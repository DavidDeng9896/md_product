# 讨论记录存档

本目录是仓库级的讨论内容存档，随时记录产品讨论、决策与当日笔记。不按产品模块拆分，所有模块的讨论都写在这里。

## 怎么记

| 文件 | 用途 |
| --- | --- |
| [MEMORY.md](./MEMORY.md) | 跨会话的项目记忆：已定决策、功能定位、关键文件索引。结论变了就改这里。 |
| `YYYY-MM-DD.md` | 当日讨论流水：当天做了什么、达成了什么、还剩什么。一天一篇，不要事后改写历史。 |

## 记录原则

- 当天有讨论就写当天日期文件，不要攒着补。
- 已闭环的决策同步写入 `MEMORY.md`，避免只散落在日志里。
- 定稿后的设计说明放到对应产品模块目录（如 `registry/discussions/`），这里只留讨论过程与记忆。
