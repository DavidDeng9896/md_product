# 明度智云 MSP — 7 种业务类型默认属性完整对比

> 数据来源：明度智云 MSP 系统 pre01 环境（https://mdzy-msp-pre01.mingdutech.cn），通过"新增物料类型"弹窗逐一切换 7 种业务类型实际查看所得。
> 查看时间：2026-09-14

---

## 一、总体概览

| 业务类型 | 基础信息字段数 | 批次信息字段数 | 合计 |
|----------|---------------|---------------|------|
| 普通物料 | 11 | 13 | 24 |
| 细胞 | 7 | 12 | 19 |
| 质粒 | 7 | 25 | 32 |
| 菌种 | 7 | 16 | 23 |
| 病毒 | 7 | 15 | 22 |
| 抗体 | 7 | 21 | 28 |
| 引物 | 7 | 14 | 21 |

**关键发现**：6 种生物类物料（细胞/质粒/菌种/病毒/抗体/引物）的**基础信息字段完全一致**，均为 7 个；差异全部体现在**批次信息**中，且每种业务类型都有其领域特有的字段。

## 四、共性与差异总结

### 4.1 所有业务类型共享的基础字段（5 个）

| 字段 | 类型 |
|------|------|
| 物料编号 | 特殊 |
| 物料名称 | 文本 |
| 别名 | 文本 |
| 注册数据 | 特殊 |
| 生产厂家 | 列表 |

### 4.2 所有业务类型共享的批次字段（5 个）

| 字段 | 类型 |
|------|------|
| 批次号 | 文本 |
| 检测状态 | 特殊 |
| 有效期至 | 时间 |
| 所属项目 | 特殊 |
| 来源实验 | 列表 |

### 4.3 生物类物料共享的特有字段

| 字段 | 出现的业务类型 |
|------|---------------|
| 序列图谱 | 细胞、质粒、菌种、抗体、引物（病毒无） |
| 构建人 / 构建时间 | 质粒、菌种 |
| 供应商 / 货号 / 附件 | 质粒、菌种、病毒、抗体、引物（细胞无） |

### 4.4 各业务类型最具辨识度的独有字段

| 业务类型 | 标志性独有字段 |
|----------|---------------|
| 普通物料 | COA、出厂批号、生产日期、产地、厂家 |
| 细胞 | 父细胞、代次、培养基、生长特性、冻存条件、种属来源、组织来源、适应症 |
| 质粒 | 克隆号、克隆菌株、特征基因、父质粒、载体、载体类型、启动子、抗性、拷贝数、质粒用途、生长条件 |
| 菌种 | 关联质粒、抗性、拷贝数 |
| 病毒 | 父病毒、代次、血凝价、EID50、TCID50 |
| 抗体 | 源物种、目标物种、VR序列、重链、轻链、VDJ、存储温度、稀释比例 |
| 引物 | 序列（长文本）、融化温度、预期用途 |

## 五、字段数量排名

1. **质粒** — 32 个字段（基础 7 + 批次 25），字段最丰富，覆盖克隆、载体、构建全流程
2. **抗体** — 28 个字段（基础 7 + 批次 21），覆盖抗体序列、链型、物种来源等
3. **普通物料** — 24 个字段（基础 11 + 批次 13），基础信息字段最多
4. **菌种** — 23 个字段（基础 7 + 批次 16）
5. **病毒** — 22 个字段（基础 7 + 批次 15）
6. **引物** — 21 个字段（基础 7 + 批次 14）
7. **细胞** — 19 个字段（基础 7 + 批次 12），字段最少
