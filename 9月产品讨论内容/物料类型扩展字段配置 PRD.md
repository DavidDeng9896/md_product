# 文档说明

本文档定义明度数智 MSP（Inventory 实验物料管理）中「物料类型 → 扩展信息 → 新增字段」功能的产品行为与验收口径，供产品、前端、后端、测试与业务配置人员共用。

读者对象：研发与测试同学依据本文实现并验收扩展字段的渲染、存储与校验；业务配置人员依据「字段选型指引」在物料类型上配置扩展属性。

# 范围与术语

## 本文范围

- 物料类型维度下的自定义扩展字段配置；

- 支持的 11 种字段类型及其配置项、存储值与校验规则；

- 字段在物料主数据表单与实验页面的渲染与显隐控制。

## 非目标

- 不改动物料主数据已有的固有基础字段（物料编号、名称、规格、批次号、COA 等）；

- 不定义通用配置字典（仓库类型、供应商等）自身的维护规则，仅消费其选项；

- 不覆盖物料申领、出入库、盘点等业务单据上的字段渲染（仅在物料主数据与详情页生效）。

## 术语

|术语|含义|
|---|---|
|物料类型|普通物料 / 细胞 / 质粒 / 菌种 / 病毒 / 抗体 / 引物等业务分类，扩展字段按类型维度配置|
|物料主数据|在某个物料类型下新增的具体物料实例，自动继承该类型的扩展字段|
|扩展属性|在物料主数据固有字段之外，由业务自定义的字段，区别于「固有属性」|
|关联数据源|绑定系统【通用配置】字典，选项随字典维护自动同步；不绑定则为手动录入的固定选项|
|表单属性 key|后端存储与接口识别该扩展字段的唯一编码|

# 入口与公共配置

## 入口路径

菜单：物料配置 → 物料类型 → 编辑某物料类型 → 扩展信息 → 新增 → 在弹窗中选择字段类型并完成配置。

## 所有字段通用配置项

|配置项|说明|
|---|---|
|字段名称|前端表单展示标签，业务用户可见；同一物料类型下不可重复|
|是否只读|是：物料主数据表单仅展示，不可编辑；否：允许新增 / 修改 / 清空|
|表单属性 key|后台唯一编码，数据库与接口识别字段；全局不可重复|
|校验条件|自定义校验规则；不同字段类型支持的具体规则见各类型说明|
|必填项|开启：提交物料主数据时必须通过该校验，否则拦截保存；关闭：允许空值提交|

## 仅选项类字段特有的配置

复选框、单选框、下拉选择框三类支持：

- **行数据**：候选选项列表；

- **关联数据源**：

    - 关联数据源：绑定【通用配置】下的字典，字典变更时物料表单选项同步更新；

    - 不关联数据源：手动录入固定选项，不随字典变化。

其余 8 种字段类型均无行数据、不支持关联数据源。

# 字段类型明细

## 复选框（Checkbox）

- 组件：多选选项组件，可同时勾选多项；

- 特有配置：行数据、关联数据源；

- 存储值：多选项集合（数组）；

- 必填规则：开启必填时，至少勾选一项方可提交；

- 典型场景：物料危险特性、适用实验类型、多标签分类。

## 单选框（Radio）

- 组件：选项平铺展示，只能选中一项；

- 特有配置：行数据、关联数据源；

- 存储值：单个选项值；

- 必填规则：开启必填时，必须选择其中一项；

- 典型场景：危险等级（高/中/低）、是否致癌（是/否）等选项较少、希望一眼可见的单选。

## 下拉选择框（Select）

- 组件：点击展开下拉面板单选，节省页面空间；

- 特有配置：行数据、关联数据源；

- 存储值：单个选项值；

- 必填规则：开启必填时，必须选择其中一项；

- 典型场景：物料储存环境、物料级别、供应商等选项较多的单选。

## 单行文本输入框（Input）

- 组件：单行短文本录入，不支持换行；

- 特有配置：无；校验可配最大字符长度、正则、禁入字符；

- 存储值：单行文本字符串；

- 必填规则：开启必填时，必须录入文本；

- 典型场景：货号、品牌简称、简短编码、单行备注。

## 多行文本输入框（Textarea）

- 组件：文本域，支持换行分段录入长文本；

- 特有配置：无；校验可配最大字符长度；

- 存储值：带换行的长文本字符串；

- 必填规则：开启必填时，必须录入文本；

- 典型场景：安全注意事项、风险描述、详细储存要求、前处理说明。

## 计数器（InputNumber）

- 组件：数字输入，自带加减按钮，支持手动输入数字；

- 特有配置：无；校验可配最小值、最大值、小数位数；

- 存储值：数值；

- 必填规则：开启必填时，必须录入数字；

- 典型场景：可使用次数、分装份数、允许取样次数。

## 滑块（Slider）

- 组件：可视化滑动条，在设定区间内选取连续数值；

- 特有配置：无；校验需配置最小值、最大值、步长；

- 存储值：区间内连续数值；

- 必填规则：开启必填时，必须选定数值；

- 典型场景：风险评分、纯度百分比、活性等级分值。

## 开关按钮（Switch）

- 组件：布尔二态组件，仅「开启 / 关闭」两种状态；

- 特有配置：无；固定二值，不维护选项；

- 存储值：布尔值（true / false）；

- 必填规则：开启必填时，必须选定开 / 关状态，不能为空；

- 典型场景：是否易制毒、是否低温保存、是否有毒、是否需特殊审批。

## 时间选择框（DatePicker）

- 组件：日历 / 时间面板，拾取单点时间；

- 特有配置：无；校验可限制不可选未来时间等规则；

- 存储值：标准时间值，可空；

- 必填规则：开启必填时，必须选择时间；

- 典型场景：物料接收时间、首次开封时间、稳定性起始时间。

## 图片（Image Upload）

- 组件：图片上传与预览组件，仅接受图片格式，支持放大预览；

- 特有配置：无；校验可限制图片格式与单张大小；

- 存储值：图片资源访问链接；

- 必填规则：开启必填时，必须上传图片；

- 典型场景：物料实物照片、标签照片、结构式实拍图。

## 上传（File Upload）

- 组件：通用附件上传，支持 PDF / Word / Excel 等多类型文件，支持多文件、下载与预览；

- 特有配置：无；校验可限制文件类型、单文件大小、上传数量上限；

- 存储值：文件资源访问链接（可多值）；

- 必填规则：开启必填时，必须上传文件；

- 典型场景：MSDS 安全说明书、COA 质检报告、资质证书。

# 字段选型指引

|业务诉求|推荐字段|
|---|---|
|多个标签 / 多特征 / 多分类同时成立|复选框|
|选项少、希望页面一眼看到全部选项的单选|单选框|
|选项较多、希望精简页面的单选|下拉选择框|
|简短编码 / 短备注|单行文本|
|大段描述、分段说明|多行文本|
|离散计数（次数、份数、份数）|计数器|
|连续区间数值、需要可视化|滑块|
|是 / 否二值标记|开关按钮|
|记录某个时间点|时间选择框|
|仅图片、需要放大预览|图片|
|PDF / Word 等文档、证书、报告附件|上传|

# 约束规则与验收要点

1. 扩展字段归属**物料类型**，同类型下所有物料主数据自动继承；在物料类型上新增 / 修改 / 删除扩展字段，需对该类型下已有物料主数据生效。

2. 扩展字段不得与物料主数据已有固有字段重名或同义覆盖；表单属性 key 全局唯一。

3. 选项类字段（复选框 / 单选框 / 下拉）选择「关联数据源」后，候选选项从【通用配置】字典实时读取；字典增删选项后，已配置字段在物料主数据表单上的候选集同步更新，已保存的历史取值不得被强制清空。

4. 所有扩展字段均需支持「是否只读」「必填」「自定义校验条件」；只读模式下不出现新增 / 修改 / 清空入口。

5. 扩展字段可在「实验中显示字段」模块独立控制是否在实验相关页面展示，与物料主数据页面的展示解耦。

6. 文件 / 图片类字段需落库为资源链接，并在物料详情页支持预览与下载。

# 渲染位置

- 物料主数据新增页；

- 物料主数据编辑页；

- 物料详情页；

- 按「实验中显示字段」配置，可选地渲染于实验相关页面。

# 开放问题

- 各字段类型的「校验条件」具体规则集（如单行文本正则、计数器小数位、滑块步长）需要后端与前端在实现前进一步对齐；

- 图片 / 上传字段的单文件大小上限、总数量上限需按系统存储策略最终确认；

- 扩展字段在自定义报表、库存台账中的查询与筛选支持范围待与报表模块确认。
