# 对象复制映射维度扩展（对象 ↔ 物料主数据）— 设计讨论记录

> 对象复制的映射机制从"对象 → 对象"扩展到"对象 ↔ 物料主数据（物料类型）"。  
> 痛点：实验产物对象创建时需同步录入样品物料/库存相关信息，两侧共用字段（名称、批号、浓度、纯度、有效期、厂家、COA 等）重复填写，录入复杂且易错；统一两套数据模型则涉及物料主数据侧大量改造，代价不可接受。
>
> 状态：**决策已全部闭环（2026-09-15）**。可进入正式功能设计说明编写；弹窗形态留待原型阶段。

## 1. 已确认决策

| #  | 决策点     | 结论                                                                                          |
| -- | ------- | ------------------------------------------------------------------------------------------- |
| 1  | 映射配置位置  | **统一配置在对象上**（2026-09-15 更新）：对象的映射关系设置中并存两类映射——①**对象模型映射**（对象↔对象，原对象复制功能）；②**对象与物料信息映射**（对象↔物料主数据，本扩展）。物料类型侧不设配置入口，1:1 绑定约束不变（决策 #6） |
| 2  | 复制方向    | **双向均支持**：对象→物料主数据、物料主数据→对象                                                                 |
| 3  | 映射字段范围  | **仅基础信息 + 扩展信息，批次信息不映射**（2026-09-15 更新，替代原"批次字段作为普通字段参与映射"结论）：主数据层只映射物料类型的基础信息字段与扩展字段；批次相关内容（批号、有效期至、父细胞、序列图谱、检测状态、来源实验等批次字段）不属于主数据复制映射范围 |
| 4  | 主数据判重策略 | **阻断并提示复用**：复制提交时按**物料类型配置的"主数据唯一性校验"**（可配置多个字段组合判定）进行判重 → 阻断提交，提示用户复用已有主数据（不新建重复主数据）       |
| 5  | 主数据编号规则 | **沿用现有规则**（2026-09-15 确认）：系统按编号规则自动生成，新增时支持修改；不继承源对象编号 |
| 6  | 映射数量关系  | **一个对象可配置多个不同物料类型的映射；但一个物料类型只能被一个对象的映射绑定**（物料类型侧一对一，全局唯一）                                   |
| 7  | 特殊字段映射  | 父细胞（指向库内细胞编号）、关联序列（指向序列库）、COA/附件、化合物等特殊类型字段——**后续单独专项讨论**                                   |
| 8  | 溯源机制    | **注册数据锚点 + 批号对应**：对象→物料主数据复制时，自动写入物料主数据"注册数据"字段指向源对象实体（需物料类型开启该字段）；同时批号与源对象编号保持一致。不另建来源关联字段 |
| 9  | 入口与权限   | 物料侧不做源侧推送入口；权限体系不与资源管理菜单权限对齐                                                                |
| 10 | 同公司约束   | **沿用**对象复制的前置约束：源对象与物料类型/主数据必须属于同一公司，跨公司禁止配置映射与复制 |
| 11 | 列表/选项类字段映射 | **同名选项自动匹配 + 不可匹配留空**（2026-09-15 确认）：对象下拉字段值与物料列表/选项字段候选值按名称自动匹配；匹配不上的值留空（必填项则阻断，用户弹窗补充） |
| 12 | 主数据→对象遇工作流 | **进"待审批"**（2026-09-15 确认）：目标对象开启工作流时，物料主数据→对象的复制入库同样走"待审批"临时状态，规则与对象复制一致 |
| 13 | 主数据初始状态与前置校验 | **默认"启用"**（2026-09-15 确认）；复制前置条件：物料类型需处于"已发布 + 启用"状态（与手动新增主数据校验一致） |
| 14 | 双向确认弹窗形态 | **延后至原型设计阶段确定**（2026-09-15 确认，本阶段不做决策） |
| 15 | 判重命中后的处理 | **自动复用，不新建**（2026-09-15 确认，细化决策 #4）：复制时命中物料类型"主数据唯一性校验"→ 不新建主数据，该入库物料**直接引用已有主数据**；源对象实体不受影响。即用户无需手动复用，系统自动挂接 |
| 16 | 只读扩展字段的复制写入 | **允许写入**（2026-09-15 确认）：物料扩展字段"是否只读"约束的是表单交互层（防用户手动编辑）；对象复制属于**新增初始化**场景，系统写入不受只读限制 |
| 17 | 字典变更与历史取值 | **老数据不清，新数据按最新匹配**（2026-09-15 确认）：扩展字段关联数据源（字典）变更后，既有主数据历史取值不清空（沿用既有约束）；复制新增的数据按最新字典选项进行文字匹配 |

## 2. 映射关系模型

```
（物料类型侧一对一约束）

对象 A ────映射1────► 物料类型 T1（细胞-XX）
       ────映射2────► 物料类型 T2（质粒-YY）     ← 一个对象可配多个物料类型
       ────映射3────► 物料类型 T3

对象 B ────映射4────► 物料类型 T4

物料类型 T1 ──已被 A 绑定──► 对象 B 不可再绑定 T1  ← 一个物料类型只能配一个对象
```

双向复制均基于同一套映射配置执行：

- **对象 → 物料主数据**：对象实体详情/列表"复制到..."，选择已配映射的物料类型，确认后在该物料类型下生成主数据
- **物料主数据 → 对象**：主数据侧发起（入口形式待定，见待讨论 #3），选择已配映射的对象，确认后在目标对象下生成新实体

## 3. 与原对象复制规则的差异对照

| 维度   | 对象 → 对象（原）               | 对象 ↔ 物料主数据（本扩展）                                     |
| ---- | ------------------------ | --------------------------------------------------- |
| 配置位置 | 目标对象-数据映射                | 对象的映射关系设置中并存"对象模型映射"与"对象与物料信息映射"两类（配置入口统一在对象上） |
| 映射字段 | 对象全部可映射字段                | **仅物料类型的基础信息 + 扩展信息**（批次信息、系统字段不映射） |
| 数量关系 | 多对一汇聚；同源同目标至多一套映射（单源单映射） | 对象 1:N 物料类型；物料类型 1:1 对象（物料类型侧唯一绑定）                  |
| 判重   | 纯新建，重复复制=多条，不判重          | 命中物料类型"主数据唯一性校验"（多字段组合）→ **阻断并提示复用已有主数据**                  |
| 溯源   | 内置系统级"来源关联"字段+来源标签       | "注册数据"字段指向源实体 + 批号=源对象编号保持对应 |
| 编号   | 目标按自身名称规则重新编号，不继承源       | 主数据编号自动生成、新增时可修改（沿用现有规则，不继承源编号）                     |
| 校验   | 必填项（关键项）空则阻断             | 同左 + 主数据唯一性校验阻断                                     |
| 字段结构 | 双方均为对象模型，字段类型体系一致        | 物料类型侧字段为"基础信息（按业务类型）+扩展字段"，类型体系不同，兼容规则需适配 |

## 5. 两侧字段体系对照（依据：物料类型默认属性.md + Registry 科学数据注册.md）

### 5.1 物料类型侧字段类型体系与映射范围

物料类型默认属性中的字段类型：**文本、数值、时间、列表、附件、特殊、长文本、序列文件、人员选择**。

**映射范围（2026-09-15 确认）：仅基础信息 + 扩展信息。** 批次信息字段全部不参与映射。

**范围内（基础信息）的特殊字段**：

| 特殊字段 | 所属 | 含义 | 映射处理 |
| --- | --- | --- | --- |
| 物料编号 | 基础信息（所有类型） | 主数据编号，自动生成可编辑 | 系统自动生成，新增时可修改（决策 #5）；不作为映射行配置 |
| 注册数据 | 基础信息（所有类型） | 关联 Registry 注册实体（见 5.2） | 复制时系统自动写入，指向源对象实体（决策 #8） |
| 化合物 | 基础信息（普通物料） | 关联化合物库；与【注册数据】互斥（同类型只显示其一） | **不参与映射**（化合物为老业务，新业务中对象侧已支持化合物类型） |

**范围外（批次信息，全部不映射）**——以下特殊字段因批次出范围而自动消解：

| 字段 | 原待讨论问题 |
| --- | --- |
| 检测状态、批次号、有效期至、所属项目、来源实验 | 批次字段，出范围 |
| 父细胞/父质粒/父病毒/关联质粒/引物/特征基因 | 批次字段（原"关联递归"候选），出范围 |
| 序列图谱（序列文件） | 批次字段（原"序列内容文件级映射"候选），出范围 |
| COA/附件、供应商、货号 | 批次字段，出范围 |

范围外字段说明：批次相关内容在产物入库/预入库登记环节录入（走原有入库链路），不属于主数据复制映射的职责。

### 5.2 Registry 对象侧相关能力

- **注册数据字段（物料类型基础信息可选项，默认不显示）**：设为显示时，物料主数据支持选择 Registry 科学注册数据；**注册数据编号参与主数据的唯一校验**；选中后同步更新物料名称为"编号 (名称)"格式；普通物料中【化合物】与【注册数据】互斥——本扩展中**化合物字段不参与映射**（老业务，新业务对象侧已支持化合物），映射配置侧不受互斥影响
- **物料主数据入口**：物料库-物料配置-物料主数据、ELN-实验记录-产出入库模块
- **关联物料 tab（Registry 对象详情）**：与注册数据关联的物料在实体详情"关联物料"tab 显示库存信息（容器号、批次、物料编号、物料名称，支持搜索；默认不显示无剩余量物料）
- **主数据导入模板**：启用注册数据字段的物料类型，导入模板增加【注册对象】【注册数据】列（注册对象选择同公司对象，注册数据用户输入对象编号）

### 5.3 字段类型映射兼容矩阵（对象 → 物料主数据，仅基础信息+扩展信息）

| 物料侧字段类型 | 可接受的对象侧类型 | 处理方式 |
| --- | --- | --- |
| 文本/长文本 | 文本/数字/日期/下拉 | 转字符串 |
| 数值 | 数字 | 直接；文本需校验可转数值 |
| 时间 | 日期 | 按目标格式转换（基础信息中时间字段较少） |
| 列表 | 下拉/文本 | **同名选项自动匹配 + 不可匹配留空**（决策 #11）；列表来源为通用配置（可关联数据源字典） |
| 附件/图片 | 附件/图片 | 文件复制（图片为生物类基础信息字段） |
| 特殊-物料编号 | — | 系统自动生成（决策 #5），非映射行 |
| 特殊-注册数据 | — | 复制时系统自动写入指向源实体（决策 #8），非映射行 |
| 特殊-化合物 | — | 不可映射（老业务，排除） |

**已出范围**：序列文件、人员选择（构建人）、父细胞/父质粒/父病毒/关联质粒、检测状态、注册数据以外的批次字段——均属批次信息，不映射。

扩展信息字段的字段能力与兼容方案：见 5.5 节（依据《物料类型扩展字段配置 PRD》）。

### 5.4 业务类型字段清单速查

7 种业务类型（普通物料/细胞/质粒/菌种/病毒/抗体/引物）的完整字段清单见《物料类型默认属性.md》。要点：

- 6 种生物类物料基础信息字段完全一致（7 个）：物料编号、物料名称、别名、注册数据、外文名称、生产厂家、图片
- 普通物料基础信息独有：规格型号、浓度、纯度、含量、化合物、级别
- 所有类型共享批次字段（5 个）：批次号、检测状态、有效期至、所属项目、来源实验
- 质粒字段最多（32 个），细胞最少（19 个）
- "来源实验"（列表）指向 ELN 实验记录，对象复制场景下源对象若有实验关联可考虑映射

### 5.5 扩展字段能力与对象字段的映射方案（依据：物料类型扩展字段配置 PRD）

物料类型扩展信息支持 **11 种字段类型**，通用配置项：字段名称（同类型内唯一）、是否只读、表单属性 key（全局唯一）、校验条件、必填项。其中复选框/单选框/下拉选择框支持"行数据 + 关联数据源"（绑定【通用配置】字典，选项随字典同步；不绑定则为手动固定选项）。

**对象字段 → 物料扩展字段兼容矩阵**：

| 物料扩展字段类型 | 可接受的对象侧类型 | 处理方式 |
| --- | --- | --- |
| 单行文本 | 文本/数字/日期/下拉 | 转字符串 |
| 多行文本 | 文本（多行优先）/文本 | 转字符串（换行保留） |
| 计数器 | 数字 | 直接；文本需校验可转数值；需满足最小值/最大值/小数位校验 |
| 滑块 | 数字 | 直接；需满足区间（最小/最大值）校验 |
| 开关按钮 | 勾选 | 布尔直搬 |
| 时间选择框 | 日期 | 按目标格式转换 |
| 单选框 | 下拉（单选） | 同名选项自动匹配 + 不可匹配留空（决策 #11） |
| 下拉选择框 | 下拉（单选） | 同名选项自动匹配 + 不可匹配留空（决策 #11） |
| 复选框 | 下拉（多选） | 逐值同名匹配；部分匹配则仅搬匹配项，全部不可匹配留空 |
| 图片 | 图片/附件 | 文件复制（图片格式） |
| 上传 | 附件 | 文件复制（多文件支持） |

**选项匹配的两种来源**（决策 #11 细化）：
- 扩展字段**关联数据源**（通用配置字典）：按字典当前选项与对象字段值同名匹配
- 扩展字段**手动行数据**（固定选项）：按固定选项与对象字段值同名匹配

**校验衔接**：复制写入需过扩展字段的校验条件（最大长度、正则、数值区间、步长等）与必填项约束——必填且映射不上时，沿用"阻断 + 弹窗补充"策略；非必填留空。

**遗留细节**（待讨论 #9、#10）：
- "是否只读"字段复制写入是否允许（只读是表单层还是数据层约束）
- 关联数据源字典变更后"历史取值不得强制清空"的既有约束与复制写入的兼容性
