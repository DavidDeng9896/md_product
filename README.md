# md_product

产品相关文件与讨论内容的存放仓库。

## 目录结构

```
md_product/
├── notes/             # 讨论记录存档（随时记录）
├── registry/          # Registry 科学数据注册
├── eln/               # ELN 电子实验记录
└── 资源管理/           # 资源管理系统
```

---

| --- | --- |
| [MEMORY.md](./notes/MEMORY.md) | 项目记忆：已定架构决策与关键文件 |

### 模块内文档类型

| 类型 | 目录 | 用途 |
| --- | --- | --- |
| 正式设计 | 模块根目录 | PRD、功能设计说明，用于评审与交付 |
| 设计讨论 | `discussions/` | 讨论记录与定稿前的设计稿 |
| 原型 | `prototype/` | HTML 原型、截图、验证脚本 |
