# md_product

产品相关文件与讨论内容的存放仓库。

## 归档规范

文档按 **月份 → 产品模块 → 文档类型** 组织：

| 层级 | 说明 | 示例 |
| --- | --- | --- |
| `docs/YYYY-MM/` | 按月份归档 | `docs/2026-09/` |
| 产品模块 | 按产品线或子系统划分 | `registry/`、`物料类型/`、`eln/` |
| 文档类型 | 模块内按用途分层 | 正式设计、讨论稿、原型、笔记 |

### 文档类型说明

| 类型 | 目录 | 用途 |
| --- | --- | --- |
| 正式设计 | 模块根目录 | PRD、功能设计说明，用于评审与交付 |
| 设计讨论 | `discussions/` | 讨论记录与定稿前的设计稿 |
| 原型 | `prototype/` | HTML 原型、截图、验证脚本 |
| 讨论笔记 | `notes/` | 每日记录、决策记忆 |
