## 需求背景

ELN「样品」菜单里，样品池管的是请验任务：一次请验同时生成请验单号、样品批号、条码，后续收样、检测、结果都挂在这次请验上。系统里没有一份「真实产生出来的样品」主档，因此无法回答：

1. 这份产出还剩多少、有没有进物料库；
2. 同一份样品能不能多次请验；
3. 实验里能不能直接使用他人产出、仍有剩余的样品。

**解法**：在 ELN「样品」下新增样品库。样品库管物和量，样品池继续管请验。请验从样品台账发起。

# 一、样品台账

## 1.1 台账主档

| **A、概述** |  |
| --- | --- |
| **功能编号** |  |
| **功能模块**<br>**访问入口** | ELN-样品-样品库 |
| **功能说明** | 一条样品台账对应一条注册对象，记录产出量、未入库剩余、留样、入库量和物料库存关联。身份用注册对象编号，不另造样品主数据。 |
| **权限** | 沿用来源注册对象的数据权限：创建人、所属部门是否可见、项目成员是否可见、对象上已有的分享范围。样品库不再做一层领用审批。 |
| **B、功能点** |  |
| **功能点** | **描述** |
| 列表 | 1. 展示样品台账：对象编号/名称、来源（产物登记 / 已有注册对象）、归属人、产出量、台账剩余、留样量、入库量、库存剩余、状态<br>2. 库存剩余从物料库取，不在台账上手改<br>3. 支持按编号、名称、来源、状态筛选 |
| 详情 | 1. 量卡片：产出量 / 台账剩余 / 留样量 / 入库量 / 库存剩余<br>2. 流水时间线（见 1.3）<br>3. 关联请验单（1:N）<br>4. 关联物料容器（有入库时） |
| 身份 | 一条注册对象一条台账。一次产物登记注册出一条新对象，对应一条新台账，不往旧台账上累加 |
| 编号 | 样品身份 = 注册对象编号。请验仍生成自己的请验单号和样品批号；样品批号继续表示这一次送检 |

## 1.2 量字段

| 字段 | 含义 | 可否手改 |
| --- | --- | --- |
| 产出量 | 登记时的初始量，之后不改 | 否 |
| 台账剩余量 | 还没进物料库的量，含留样量 | 否，只随流水变 |
| 留样量 | 台账剩余里冻结的部分 | 否，只随留样 / 销毁留样变 |
| 入库量 | 累计从台账转进物料库的量。不入库则为 0 | 否，只随入库变 |
| 库存剩余量 | 物料库里这份库存现在还剩多少 | 否，从物料库取 |
| 单位 | 登记时带上的计量单位或包装单位 | 否。沿用现有单位，不做换算 |

**可用量** = 台账剩余量 − 留样量。请验、实验使用、入库只扣可用量。

**恒等**（累计消耗只含扣在台账剩余上的请验和实验使用，不含扣在容器上的量）：

```text
产出量 = 台账剩余量 + 累计消耗 + 入库量 + 累计销毁
```

库存剩余不进这条等式。入库量是转出去的累计数；库存剩余会因容器扣减继续变小。

## 1.3 流水

每笔动作写一行：时间、操作人、类型、数量、台账剩余的前后值、去向（请验单 / 实验记录 / 物料容器）。

| 动作 | 对量做什么 |
| --- | --- |
| 登记 | 写出产出量，台账剩余 = 产出量 |
| 请验消耗 | 见第二章。未入库扣可用量；已入库扣容器 |
| 实验使用 | 与请验同一套扣量 |
| 留样 | 增加留样量，不减少台账剩余。可用量变少 |
| 销毁留样 | 用户填写销毁数量。留样量和台账剩余同时减少。不自动到期，不把留样改回可用量 |
| 入库 | 从可用量转到入库量，写物料容器和库存关联 |
| 销毁 | 从台账剩余里尚未留样的部分扣减。不替物料库销毁已入库的实物 |

## 1.4 状态

状态不表示实物在不在仓库。不设「在库」「已移交」「留样」。

| 状态 | 条件 |
| --- | --- |
| 可用 | 台账剩余 > 0，或库存剩余 > 0。部分消耗、部分入库、只销毁了一部分留样，都还是可用 |
| 已耗尽 | 台账剩余 = 0 且库存剩余 = 0，量是被请验、实验使用或物料库消耗掉的 |
| 已销毁 | 台账剩余 = 0 且库存剩余 = 0，并且使台账剩余归零的是用户销毁 |

已耗尽、已销毁后不可再请验、不可再实验使用、不可再入库。可用状态下，只要对应侧还有量，就可以继续操作。

# 二、请验与实验使用

## 2.1 从台账发起请验

| **A、概述** |  |
| --- | --- |
| **功能模块**<br>**访问入口** | 样品库详情 / 列表「发起请验」 |
| **功能说明** | 选中样品后创建请验单，请验单指向该样品，进入现有样品池。一个样品可多次请验。检测、收样、结果仍走现有请验流程。 |
| **权限** | 能查看该样品（即能查看来源对象）+ 现有请验权限 |
| **B、功能点** |  |
| **功能点** | **描述** |
| 前置 | 1. 样品状态为可用<br>2. 来源对象为有效。待审批 / 审批中可有台账，但不能请验<br>3. 可用量 > 0，或关联容器剩余 > 0 |
| 扣量 | 1. **未入库**：填写使用量，从可用量扣减，写请验消耗流水<br>2. **已入库**：带出该样品关联、剩余量 > 0 的容器；用户选择容器并填写使用量，物料库扣该容器剩余。使用量不能大于容器剩余；容器若是整体出库，按物料库现有规则整容器扣减<br>3. 同一次请验可以只扣台账剩余、只扣容器，或两边都扣。两边各写各的流水，容器用量不改台账剩余和入库量<br>4. 库存剩余按物料库结果回写 |
| 落库 | 生成现有请验单（请验单号、样品批号、条码照旧），请验单记录样品、容器（如有）和使用量 |

## 2.2 实验记录中使用样品

| **A、概述** |  |
| --- | --- |
| **功能模块**<br>**访问入口** | ELN 实验记录「使用样品」 |
| **功能说明** | 实验里选择样品库中可用的样品，包括他人产出、权限允许的样品。扣量规则与请验相同。 |
| **权限** | 来源对象的数据权限（创建人 / 部门可见 / 项目可见 / 分享范围）。不做领用审批 |
| **B、功能点** |  |
| **功能点** | **描述** |
| 选择 | 列出状态为可用、来源对象为有效、当前用户有权使用的样品 |
| 扣量 | 与 2.1 相同：未入库扣可用量；已入库选容器扣物料 |
| 落库 | 实验记录记下样品、容器（如有）和使用量；样品流水记下实验记录 |

送检和实验使用都按消耗处理，不做成借出再退回。

# 三、登记、入库、留样、销毁

## 3.1 产出登记生成台账

| **A、概述** |  |
| --- | --- |
| **功能模块**<br>**访问入口** | ELN 实验记录-产物登记 |
| **功能说明** | 产物登记把产出注册成对象时，自动生成样品台账。这一步只落对象和产出量，不写容器、不写仓库。 |
| **B、功能点** |  |
| **功能点** | **描述** |
| 触发 | 产物登记保存并完成对象注册 |
| 写入 | 1. 生成台账，来源 = 该对象 + 实验记录<br>2. 产出量由用户在登记时填写；台账剩余 = 产出量；留样量 = 0；入库量 = 0；状态 = 可用<br>3. 工作流：对象待审批 / 审批中时台账仍生成，但不能请验、不能被实验使用，审批通过变为有效后才能扣量 |
| 不写 | 容器、仓库、物料库存。要进物料库时走 3.3 |

从已有注册对象手工创建台账：同样填写产出量，来源指向该对象，不写容器。

## 3.2 留样

| **功能点** | **描述** |
| --- | --- |
| 留样 | 在可用量内增加留样量。台账剩余不变，可用量变少。不拆子样品，不单建留样台账，不单独占状态 |
| 销毁留样 | 用户填写销毁数量（≤ 当前留样量）。留样量和台账剩余同时减少。不自动到期，不把留样释放回可用量 |
| 部分销毁 | 台账或库存仍有剩余时，状态仍为可用 |

## 3.3 入库

| **A、概述** |  |
| --- | --- |
| **功能模块**<br>**访问入口** | 样品库详情「入库」 |
| **功能说明** | 把台账上的可用量转给物料库。样品台账记下入库量和库存关联；位置、容器、库存剩余由物料库管。 |
| **B、功能点** |  |
| **功能点** | **描述** |
| 前置 | 状态为可用；可用量 > 0；来源对象为有效 |
| 操作 | 1. 用户填写本次入库量（≤ 可用量），并按物料库规则填写容器、仓库<br>2. 台账剩余减少，入库量增加，库存剩余由物料库给出<br>3. 可多次部分入库 |
| 之后 | 请验和实验使用改为（或同时）扣关联容器。台账剩余和入库量不再因容器消耗而变 |

## 3.4 销毁（未留样部分）

| **功能点** | **描述** |
| --- | --- |
| 范围 | 只扣台账剩余里尚未留样的部分（即可用量）。留样走 3.2 销毁留样 |
| 已入库 | 不替物料库销毁已入库实物 |
| 归零 | 销毁使台账剩余与库存剩余都为 0 时，状态 = 已销毁 |

# 四、校验策略汇总

| 场景 | 处理 |
| --- | --- |
| 请验 / 实验使用超过可用量 | 阻断 |
| 请验 / 实验使用超过容器剩余 | 阻断 |
| 容器为整体出库 | 按物料库现有规则整容器扣减 |
| 对象待审批 / 审批中 | 可有台账；不可请验、不可实验使用 |
| 无对象查看权限 | 不可见、不可用该样品 |
| 入库量超过可用量 | 阻断 |
| 销毁留样超过留样量 | 阻断 |
| 销毁超过可用量 | 阻断 |
| 已耗尽 / 已销毁 | 不可请验、不可实验使用、不可入库 |
| 存量请验 | 不迁移、不补挂、不回写历史用量 |

# 五、与既有功能的衔接

| 模块 | 衔接说明 |
| --- | --- |
| 样品池 / 我的请验 | 继续管请验任务。新请验必须从样品台账发起；检测、收样、结果流程不变 |
| 产出登记 | 保存时只注册对象并写产出量；容器改到样品库「入库」 |
| 物料库 | 入库后样品台账引用物料容器。请验和实验使用已入库部分时，由物料库扣容器剩余 |
| 注册对象权限 | 样品可见、可使用范围完全沿用对象数据权限 |
| 注册数据工作流 | 待审批对象不能被请验或实验使用，规则与对象「不可被引用」一致 |
