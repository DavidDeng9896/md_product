## 版本说明

**文档范围**：本文仅描述 ELN **系统-实验产出** 模块中的 **入库登记** 能力（含实验记录内列表态、入库抽屉、与物料库/Registry 的衔接）。不包含样品检测、物料领用等其他 ELN 模块。

**术语约定**：

| 术语 | 含义 |
| --- | --- |
| 实验产出 / 实验产物 | 同一业务能力的不同表述；UI 模块名称为 **系统-实验产出**，物料侧称 **实验产物登记** |
| 入库登记 | 实验员在 ELN 中填写产出物信息并提交，生成 **待上架** 的预入库数据（尚未完成正式库存入账） |
| 确认入库 | ELN 侧提交登记的单次操作（不等同于库管「生成入库单」） |
| 同屏双建 | 主路径：一次提交同时 **新建** Registry 对象实体 + 物料主数据 + 预入库批次；映射用于字段对齐，不是从已有对象复制 |

## 1. 功能概述

### 1.1 功能定位

实验产出入库是 ELN 实验记录本中的嵌入式模块。实验员 **合成完成后登记入库** 时，主路径是 **同屏双建**：一次操作同时新建 Registry 对象实体与物料主数据（并登记批次/容器），再推送到资源管理 **预入库登记**，由库管上架生成入库单。

该模块解决的核心问题：

- 对象实体与物料主数据有重叠字段（名称、浓度、纯度、厂家等），**只填一遍**，按对象上已配的物料映射写入两侧；
- 批次、容器、存放位置本就不在映射里，仍在本抽屉手填；
- 产出与 **来源实验** 自动关联；物料主数据 **注册数据** 指向本次新建的对象实体；
- 与采购到货登记区分：实验产物在物料库侧 **不可改物料信息**，仅允许上架与提交。

> **本期不做**：对象已经存在、本次只新建物料/批次。该次路径有需要时另开。

### 1.2 访问入口

| 入口 | 说明 |
| --- | --- |
| ELN → 实验记录 → 正文模块 **系统-实验产出** | 主入口；模块作为 Block 嵌入实验记录流 |
| ELN → 实验记录本左侧导航 **系统-实验产出** | 快捷定位到当前实验记录下产出模块 |
| 物料库 → 物料配置 → 物料主数据 | 与「ELN-实验记录-产出入库」并列的主数据维护入口（Registry PRD） |

### 1.3 典型使用场景

1. **化学合成（主路径）**：反应完成后打开入库，选物料类型 → 一张表填完重叠字段与批次/存放 → 同时得到对象实体 + 物料主数据 + 待上架批次；
2. **生物制备**：同上，物料类型绑定细胞/质粒等对象模型时，对象独有字段（如序列相关）出现在「对象信息」区；
3. **提取/制备类实验**：与「提取液制备」等步骤区块并列，登记中间体或终产物；
4. **批量产出**：同一实验一次产生多条产出，使用「批量入库」逐条双建。

## 2. 角色与权限

| 角色 | 能力 |
| --- | --- |
| 实验记录创建人 / 协作人 | 在本实验记录下添加、编辑（草稿态）、删除产出登记；提交入库登记 |
| 实验记录只读用户 | 查看模块列表与已登记产出，不可编辑 |
| 库管 | 在 **物料管理 → 入库管理 → 预入库登记** 查看实验产物登记数据，执行上架入库、生成入库单（见第 9 节） |
| 公司管理员 | 配置物料类型字段、编号规则、仓库与审批策略 |

**权限原则**：

- 模块操作权限继承 **实验记录** 创建人/协作人权限；
- 登记数据的 **公司范围** 与实验记录所属公司一致；
- 仓库选择受 **仓库授权** 与 **锁库状态** 约束（盘点锁库时不可选择该仓库）。

## 3. 模块结构（实验记录内）

### 3.1 嵌入形态

「系统-实验产出」以可折叠 Block 形式嵌入实验记录正文，具备：

- **模块标题区**：模块名、展开/折叠、模块级操作按钮；
- **数据列表区**：展示当前实验下已登记的产出记录；
- **空状态**：无数据时显示「暂无数据」。

模块不跳转新页面；登记时在当前实验记录页 **右侧滑出抽屉**（Drawer），标题为 **入库**。

### 3.2 模块级操作

| 操作 | 说明 | 前提 |
| --- | --- | --- |
| **添加** | 打开入库抽屉，新增一条产出登记 | 实验记录可编辑 |
| **批量入库** | 对多条待登记/草稿产出批量进入入库流程 | 列表存在可批量处理的记录 |
| **删除** | 删除选中产出登记 | 仅草稿或未提交态；已推送预入库且被库管处理的记录不可删 |
| **打印** | 打印产出标签或登记信息（若配置） | 可选能力 |
| **更多操作** | 模块扩展菜单 | — |

### 3.3 列表展示（有数据时）

列表展示当前实验关联的产出登记摘要，建议列：

| 列名 | 说明 |
| --- | --- |
| 物料编号 | 按物料类型编号规则生成或手工指定 |
| 物料名称 | 主数据名称 |
| 物料类型 | 业务类型名称 |
| 批次号 | 批次标识 |
| 入库总量 | 容器数量合计 |
| 登记人 | 提交登记的用户 |
| 登记时间 | 提交时间 |
| 状态 | 草稿 / 已登记（待上架）/ 已入库 |
| 操作 | 编辑、删除、查看 |

> 具体列集可按物料类型配置扩展字段摘要；空列表时显示「暂无数据」。

### 3.4 负责人（可选）

模块可要求指定 **负责人/登记人**（从记录本成员或项目成员中选择），未指定时不允许提交。人员选择弹窗：

- 标签页：**记录本成员** / **项目成员**
- 列表列：账号、姓名、部门
- 支持搜索；底部展示已选人员；**确定** / **取消**

## 4. 入库抽屉 — 界面结构

### 4.1 抽屉概览

| 项目 | 说明 |
| --- | --- |
| 标题 | **入库** |
| 触发 | 点击「添加」、列表行「编辑」或「批量入库」 |
| 布局 | 右侧半屏 Drawer，不离开当前实验记录 |
| 分区 | 基本信息 → 扩展信息（动态）→ 批次信息 → 存放信息 |
| 分区交互 | 各分区支持展开/折叠 |

抽屉底部操作：

| 按钮 | 类型 | 行为 |
| --- | --- | --- |
| **确认入库** / **保存并入库** | 主按钮 | 校验通过后提交登记，关闭抽屉，数据进入预入库队列 |
| **保存** | 次按钮 | 保存为草稿，不推送预入库 |
| **取消** | 次按钮 | 关闭抽屉；有未保存修改时二次确认 |

> 不同环境按钮文案可能为「确认入库」或「保存并入库」，产品统一为：**主按钮 = 提交登记**。

## 5. 表单字段说明

选中物料类型后，若该类型已绑定对象物料映射，表单按 **第 10 节同屏双建规则** 渲染（重叠字段只出现一次）。未绑定映射时，退回仅物料表单，字段仍由物料类型的基础/扩展/批次配置决定。

### 5.1 基本信息

| 字段 | 必填 | 控件 | 说明 |
| --- | --- | --- | --- |
| **生成方式** | 视配置 | 下拉 | 产物产生方式（如合成、提取、发酵等）；部分物料类型显示 |
| **物料类型** / **物料分类** | 是 | 下拉 | 选择产出所属物料类型（须 **已发布 + 启用**）；切换后刷新下方动态字段 |
| **审批提示** | — | 只读标签 | 如「不需要审批」，表示该类型登记无需走审批 |
| **物料编号** | 否 | 文本 | 按物料类型编号规则 **自动生成**；可提前手工指定（若规则允许） |
| **物料名称** | 是 | 文本 | 默认提示：「根据物料分类和生成规则自动生成」；可手工修改 |
| **计量单位** | 是 | 下拉 | 随物料类型默认带出，可改 |
| **保存物料主数据** | — | — | **双建模式不出现**。提交即新建主数据。仅物料模式（无映射）可保留该勾选 |
| **注册数据** | — | — | **双建模式不出现选择器**（对象是新建的）。提交后系统写入，指向本次对象实体 |
| **化合物** | 视类型 | 结构编辑器 | 普通物料且启用【化合物】时显示；与【注册数据】互斥 |

**普通物料常见扩展基础字段**（物料类型配置为显示时出现）：

规格型号、别名、浓度、纯度、含量、生产厂家、级别、外文名称、图片等。

**生物类物料（细胞/质粒/菌种/病毒/抗体/引物）** 基础信息字段见《物料类型默认属性.md》；6 种生物类基础信息字段一致（7 个）。

### 5.2 扩展信息

按物料类型 **扩展字段配置** 动态渲染（单行文本、多行文本、计数器、下拉、开关、图片、上传等 11 种类型）。

规则：

- 必填性、只读、校验条件（长度、正则、数值区间）遵循物料类型扩展字段 PRD；
- 图片/上传类字段支持在 ELN 登记时上传附件；
- 已映射的扩展字段进入「共用信息」，不在本区重复出现（见第 10 节）。

### 5.3 批次信息

| 字段 | 必填 | 控件 | 说明 |
| --- | --- | --- | --- |
| **批次号** | 是 | 文本 | 产出批次标识；可与实验批号策略联动 |
| **备注** | 否 | 多行文本 | 最多 500 字，显示字符计数 |
| **来源实验** | 系统 | 只读/隐式 | **自动写入当前实验记录**，不在表单展示或不可编辑 |
| **有效期至** | 视类型 | 日期 | 批次字段，按物料类型配置 |
| **所属项目** | 视类型 | 下拉/文本 | 默认继承实验记录项目 |
| **检测状态** | 视类型 | 下拉 | 生物类批次字段 |
| **批号、生产日期、COA、父细胞、关联序列等** | 视类型 | 各异 | 见物料类型批次字段配置 |

> 批次字段 **永不进入映射、永不与对象字段合并展示**。

### 5.4 存放信息

#### 5.4.1 存放位置

| 字段 | 必填 | 控件 | 说明 |
| --- | --- | --- | --- |
| **容器** | 是 | 下拉 | 容器类型（瓶、管、孔板等），决定默认容器编号规则 |
| **仓库** / **存放位置** | 否 | 级联下拉 | 实验员登记阶段可填 **临时存放位置**（库房 → 仓库 → 货区/库位）；也可留空，由库管上架时指定 |
| **库位** | 视仓库 | 库位选择 | 仓库开启库位管理时，在容器明细行中选择 |

**约束**：

- 仓库处于 **盘点锁库** 状态时，不可选择；
- 仓库 **可管理物料类型** 须包含当前物料类型；
- 孔板库位须选到具体孔位（如 `库位1\1\-2\A1`）。

#### 5.4.2 容器信息明细表

通过 **「+新增」** 添加容器行。

| 列名 | 说明 |
| --- | --- |
| 序号 | 行号 |
| 容器编号 / 管理编号 | 按容器类型规则自动生成，或手工指定 |
| 数量 | 入库数量，必填 |
| 单位 | 默认继承计量单位 |
| 开瓶日期 | 容器配置字段（若启用） |
| 库位 | 仓库开启库位管理时显示；支持双击编辑、批量修改库位 |
| 操作 | 删除行 |

表格空态显示「暂无数据」。**入库总量** = 各容器数量之和，在表单底部汇总展示。

## 6. 业务规则

### 6.1 编号与命名

| 规则 | 说明 |
| --- | --- |
| 物料编号 | 按物料类型 **编号规则** 生成；实验产出登记时可编辑（若类型允许） |
| 物料名称 | 双建时进入共用信息（若已映射到对象名称）；提交后可按「对象编号 (名称)」回写物料名称（既有注册数据行为） |
| 容器编号 | 按容器类型规则生成；整体出库/整体使用策略在后续领用环节生效 |
| 批次号 | 用户填写；可与实验内部批号一致，但不要求与物料主数据编号相同 |

### 6.2 主数据与唯一性

| 场景 | 行为 |
| --- | --- |
| 同屏双建（有映射） | 同时新建对象实体 + 物料主数据 + 预入库；注册数据指向本次对象 |
| 仅物料模式勾选「保存物料主数据」 | 创建物料主数据 + 预入库登记（不建对象） |
| 未勾选 | 仅创建预入库登记（须能匹配已有主数据或允许无主数据登记，按类型策略） |
| 双建时主数据唯一性命中 | **整单阻断**，不新建对象、不新建主数据。提示已有主数据编号。本期不提供「改挂已有对象」 |
| 实验产物登记后在物料库 | **任何人都不可修改物料信息**，仅可上架与提交 |

### 6.3 保存 vs 确认入库

| 操作 | 数据态 | 下游可见性 |
| --- | --- | --- |
| **保存** | 草稿 | 仅 ELN 模块内可见，预入库登记不可见 |
| **确认入库** | 已登记（待上架） | 推送至 **预入库登记 / 已登记物料** 列表 |

### 6.4 直接上架（可选能力）

若实验员在登记时已选择 **仓库 + 库位 + 容器明细完整**，且策略允许，可支持 **直接生成入库单**（对齐资源管理「直接上架」）。默认实验产物流程为 **两阶段**：实验员登记 → 库管上架（见第 9 节）。

## 7. 校验规则

### 7.1 提交前校验（确认入库）

1. **必填字段**：物料类型、批次号、容器、容器明细至少一行且数量 > 0；共用信息与两侧未映射必填项（见 10.3）；
2. **负责人**：若模块要求指定负责人，须已选择；
3. **物料类型有效性**：类型须已发布、已启用、与实验记录同公司；
4. **容器有效性**：容器类型属于当前物料类型允许范围；
5. **仓库**（若填写）：仓库有效、未锁库、可管理当前物料类型、用户有入库业务权限；
6. **库位**（若填写）：库位有效、未被占用（孔板按孔位校验）；
7. **扩展字段 / 对象字段**：满足各自类型配置的校验；映射转换失败且该侧必填则阻断；
8. **双建**：对象基础信息（部门/项目等）可空则继承实验记录；目标对象开启工作流不阻断提交，对象进待审批。

### 7.2 校验失败交互

- 字段级：必填项标红，聚焦首个错误字段；
- 表单级：Toast 提示原因（如「请选择负责人」「当前仓库已锁库，无法使用」）；
- 不关闭抽屉，保留已填内容。

### 7.3 删除校验

- 草稿：可直接删除；
- 已登记且库管未处理：允许撤回（从预入库登记移除），需二次确认；
- 已生成入库单或已入库：不可删除，仅可通过退库/报废等下游流程处理。

## 8. 数据状态与流转

### 8.1 状态机

```text
[草稿] ──保存──► [草稿]
   │
   └──确认入库──► [已登记/待上架] ──库管上架──► [已入库]
                        │
                        └──撤回──► [草稿] 或删除
```

| 状态 | ELN 模块 | 预入库登记 | 库存 |
| --- | --- | --- | --- |
| 草稿 | 可编辑、可删 | 不可见 | 无 |
| 已登记（待上架） | 只读；可撤回 | 可见；不可改物料信息 | 无 |
| 已入库 | 只读；展示入库单链接 | 已清除 | 有 |

### 8.2 审计字段

每条产出登记记录：

- 登记人、登记时间；
- 来源实验（实验记录编号，可跳转预览）；
- 所属项目（继承实验记录）；
- 修改人、修改时间（草稿编辑时）。

## 9. 与资源管理衔接

实验产出入库登记完成后，数据进入 **物料管理 → 入库管理 → 预入库登记**（已登记物料列表）。

### 9.1 库管侧流程

```text
实验员 ELN 确认入库
    ↓
预入库登记列表（按公司可见）
    ↓
库管选择记录 → 上架入库（指定/确认仓库、库位）
    ↓
提交 → 按仓库拆分生成入库单
    ↓
入库单审批（若仓库开启）→ 已完成 → 库存增加
```

### 9.2 预入库登记侧规则（实验产物特有）

| 规则 | 说明 |
| --- | --- |
| 不可修改物料信息 | 实验产物登记的记录，物料库侧 **任何人都无法修改** 基础/扩展/批次主数据 |
| 允许操作 | 查看、选择仓库库位、上架、提交生成入库单 |
| 列表字段 | 物料编号、名称、类型、容器数量、仓库、入库总量、批次、有效期至、备注、登记人/时间 |
| 批量提交 | 相同仓库合并为一个入库单，不同仓库拆分 |

### 9.3 入库单与入库明细

- 入库单：**物料管理 → 入库管理 → 入库单**；
- 入库明细台账展示入库流水，业务类型含 **验收入库** 等；
- 入库明细/批次信息含 **来源实验** 字段，可跳转 ELN 实验预览。

## 10. 同屏双建（主路径）

实验员合成完成后点「添加」。**映射不是从已有对象抄到物料**，而是这张入库单上的 **字段对齐**：一个控件写入对象实体 + 物料主数据。

规则与 [对象复制工作流与物料映射-功能设计说明.md](../registry/对象复制工作流与物料映射-功能设计说明.md) 第三章一致。不另开「复制到物料 / 复制到对象」。

```text
选物料类型
    │
    ├─ 该类型已被某对象绑定映射 ──► 双建模式（本节）
    │
    └─ 未绑定 ──► 仅物料模式（现网表单；弱提示「未配置对象映射」；不建对象）
```

### 10.1 提交时落什么

| 落库对象 | 规则 |
| --- | --- |
| Registry 对象实体 | **新建**。编号按对象规则生成（可改）。开启工作流则进 **待审批**（临时编号） |
| 物料主数据 | **新建**。编号按物料类型规则生成（可改），**不继承对象编号** |
| 注册数据 | 物料类型开启该字段时，系统写入，指向本次对象。双建 **不出现** 选择器 |
| 预入库批次 | 来源实验 = 当前实验记录；批次字段手填 |
| 两侧写完后 | 对象变更不改主数据，主数据变更不改对象（无持续同步） |

本次创建事务允许物料的注册数据指向 **刚生成的待审批对象**（引用禁令的例外）。其他模块仍不可引用该对象。关联物料 Tab：创建人及授权人可见；他人按工作流可见性隐藏。

### 10.2 抽屉分区（有映射时）

自上而下四段。不要做成「先填对象再填物料」两张卡。

| 顺序 | 分区 | 出现什么 |
| --- | --- | --- |
| 1 | 抬头 | 物料类型（必填，切换即重算表单）。只读提示：将同时登记「{对象名称}」与物料主数据。对象编号、物料编号各一格，按各自规则预生成，可改。**不出现** 注册数据选择器、**不出现**「保存物料主数据」 |
| 2 | 共用信息 | 映射表里 **已配对** 的字段，**每个对照只出现一次**（见 10.3） |
| 3 | 对象信息 | 对象可写字段中 **未映射** 的。必填未映射始终展开；非必填收进「更多对象信息」。计算字段（关联查找/公式/汇总）不出现。部门/项目/分享人/可见范围/别名默认继承实验记录，可改 |
| 4 | 物料其他信息 | 物料基础+扩展中 **未映射** 的。必填未映射始终展开；非必填收进「更多物料信息」。计量单位/小数位按物料类型带出（系统写入，不占映射行） |
| 5 | 批次信息 | 全部批次字段。永不与对象合并 |
| 6 | 存放信息 | 容器、仓库、容器明细。永不与对象合并 |

底部仍是 **保存 / 确认入库 / 取消**。确认入库校验两侧必填后一次提交。

### 10.3 字段出现规则（重叠只填一次）

对当前物料类型命中的那套「对象 ↔ 物料」对照，逐行决定控件：

| 对照状态 | 抽屉里怎么出现 | 提交时怎么写 |
| --- | --- | --- |
| 已映射（左右都选了源/目标） | **一个控件**，放在「共用信息」。主标签用 **物料字段名**（用户在入库）；对象字段名不同则副文案「同时写入对象：{对象字段名}」。必填 = **任一侧必填即为必填**。控件取更严的一侧（有选项的用选项、有数值区间的用区间），值按既有类型兼容矩阵转换 | 同一值写入对象字段 + 物料字段 |
| 映射行「不设置」或未配该物料字段 | 不进共用信息。若该物料字段仍要采集，走「物料其他信息」 | 只写物料 |
| 对象字段未出现在任何对照行 | 走「对象信息」 | 只写对象 |
| 批次字段 | 只在批次区，即使两边碰巧同名（如项目）也不合并 | 只写物料批次 |
| 化合物（物料老字段） | 不映射。普通物料若启用化合物，放在物料其他信息，与注册数据互斥 | 只写物料 |
| 图片/附件已映射 | 共用信息里传一次，两侧各存一份副本 | 双写文件 |
| 下拉/列表已映射 | 一个控件；选项按 **同名匹配**。匹配不上：非必填留空，必填阻断并在控件下提示补选 | 写入匹配到的两侧值 |

**不出现第二遍**：已进入共用信息的字段，对象信息区、物料其他信息区都不再渲染。

**用户改共用值**：只改这一次提交的两侧落库值，不产生「以后跟着改」的同步。

### 10.4 无映射 / 校验失败

| 场景 | 处理 |
| --- | --- |
| 物料类型未绑定任何对象映射 | 仅物料模式；Toast 弱提示，**不拦截** 入库；不建对象 |
| 共用字段转换失败、该侧非必填 | 该侧留空，另一侧能写则写 |
| 共用字段转换失败、任一侧必填 | 阻断，焦点留在该控件，不另开弹窗（抽屉本身是确认页） |
| 对象未映射必填为空 | 阻断，「对象信息」展开该字段 |
| 物料未映射必填为空 | 阻断，「物料其他信息」展开该字段 |
| 主数据唯一性命中 | **整单失败**。提示已有主数据编号/名称。不新建对象、不引用已有主数据凑合入库。本期无「使用已有对象」 |
| 对象工作流开启 | 不阻断。对象待审批；物料照常进预入库 |

### 10.5 提交后回显

- ELN 模块列表：物料编号、名称、批次、状态，可点进对象标签（待审批对象仅创建人可进）；
- 物料主数据 / 预入库：注册数据为对象标签；来源实验可跳转本实验；
- Registry 对象详情 **关联物料**：有库存后展示；待审批阶段仅创建人及授权人可见。

### 10.6 本期明确不做

- 选择已有注册数据、只新建物料/批次；
- Registry 列表「复制到物料」、物料列表「复制到对象」；
- 源对象或主数据事后互相同步。

| 项目 | 说明 |
| --- | --- |
| 入口 | 模块工具栏「批量入库」 |

## 12. 边界与异常

| 场景 | 处理 |
| --- | --- |
| 实验记录锁定/归档 | 模块只读，不可新增或编辑 |
| 仓库盘点锁库 | 登记时不可选该仓库；已选则提交拦截 |
| 物料类型被禁用 | 草稿不可提交；已登记数据按存量策略处理 |
| 无仓库权限 | 允许不选仓库登记（临时存放），库管上架时指定 |
| 注册实体无权限 | 注册数据选择器不可见或选择后提交拦截 |
| 化合物与注册数据同时启用 | Toast：「当前【化合物】和【注册数据】只能显示其中一个」 |
| 网络/保存失败 | 保留表单内容，提示重试 |
