# 样品库 — 设计讨论

> 在 ELN「样品」下新增样品库，维护真实产生的样品。样品库管物和量，样品池管请验。
>
> 状态：**第二轮（2026-09-22）**。第一轮里的领用/归还、整份「已领用」「在库」状态已按讨论作废。全部入库后仍可从台账请验，扣的是关联物料容器。下面第 1 节是已拍板内容，第 2 节是模型，第 3 节是还没拍的点。

## 1. 已拍板

| # | 结论 |
| - | --- |
| 1 | 新建样品库管实物样品。样品池保留，定位为请验任务管理。请验从样品台账发起（选样品 → 创建请验），一个样品可多次请验，检测仍走现有样品池 |
| 2 | 单位沿用现有计量单位、包装单位，样品库不另做单位体系、不做换算 |
| 3 | 送检按消耗处理，不做成借出再退回。未入库的量扣台账剩余；已入库的量在请验时选择该样品关联的物料容器和使用量，由物料库扣减容器剩余 |
| 4 | 留样做轻量：记在主台账的留样量上，不拆子样品、不单建一本留样台账 |
| 5 | 不做领用、归还。那是物料库的逻辑 |
| 6 | 不设「在库」状态。实物进了物料库，位置和库存由物料库管。样品台账只记录入库了多少，并留下物料库存关联；库存剩余随物料库变化 |
| 7 | 同时覆盖两种场景：不入库（量一直在台账上消耗）；入库（台账上的量转给物料库） |
| 8 | 实验记录里通过产物登记，把产出注册成对象时，这条对象进入样品库 |
| 9 | 使用他人产出的样品要受来源对象的权限约束（同项目、同部门，以及该对象已有的可见范围），不是默认放开 |

存量请验要不要迁到新台账上，这一点还没拍。

## 2. 模型

### 2.1 样品台账是什么

一条样品台账对应一条注册对象。产物登记把产出注册成对象时，自动生成这条台账。已有注册对象也可以手工生成一条台账。身份用注册对象编号，不另造一套样品主数据。

台账上的量：

| 字段 | 含义 |
| --- | --- |
| 产出量 | 登记时的初始量，之后不改 |
| 台账剩余量 | 还没进物料库的量，含留样量 |
| 留样量 | 台账剩余里冻结的那一部分 |
| 入库量 | 累计从台账转进物料库的量。不入库则为 0 |
| 库存剩余量 | 物料库里这份库存现在还剩多少，从物料库取，不在台账里手改 |
| 单位 | 登记时带上的计量单位或包装单位 |

可用量 = 台账剩余量 − 留样量。

产出量、台账剩余、入库量、消耗、销毁之间恒等。这里的累计消耗只含扣在台账剩余上的请验和实验使用，不含扣在容器上的请验：

```text
产出量 = 台账剩余量 + 累计消耗 + 入库量 + 累计销毁
```

库存剩余量不进这条等式。入库量是转出去的累计数，库存剩余量会因容器扣减继续变小，两者可以不相等。

### 2.2 流水

每笔动作写一行：时间、操作人、类型、数量、台账剩余的前后值、去向。

| 动作 | 对量做什么 |
| --- | --- |
| 登记 | 写出产出量，台账剩余 = 产出量 |
| 请验消耗 | 生成请验单并指向本样品。未入库部分从可用量扣减；已入库部分选择关联物料的容器和使用量，扣该容器的剩余量，台账剩余和入库量不变 |
| 实验使用 | 从可用量扣减，实验记录记下该样品 |
| 留样 | 增加留样量，不减少台账剩余。可用量变少 |
| 入库 | 从可用量转到入库量，记下物料库存关联。台账剩余减少，库存剩余由物料库给出 |
| 销毁 | 从台账剩余（含留样）扣减。不替物料库销毁已入库的实物 |

实验使用只扣台账剩余。请验不同：未入库扣台账剩余，已入库扣物料容器。容器上的使用量不能大于该容器剩余量；容器若是整体出库，按物料库已有规则整容器扣减。库存剩余量随后按物料库结果回写到台账。

### 2.3 两个场景

```text
不入库：  产出 10 → 台账剩余 10 → 请验 3、实验使用 2 → 台账剩余 5
入库：    产出 10 → 入库 6 → 台账剩余 4、入库量 6、库存剩余 6
          之后物料库再消耗，只改库存剩余；台账剩余仍是 4，还可继续请验或实验使用
全部转入：产出 10 → 入库 10 → 台账剩余 0、入库量 10
          仍可从台账发起请验：选中关联容器，填使用量，物料库扣容器剩余
          台账剩余、入库量不变，库存剩余变为扣减后的值
```

### 2.4 状态

状态看台账侧还有没有量，不表示实物在不在仓库。

| 状态 | 条件 |
| --- | --- |
| 可用 | 台账剩余量 > 0。部分消耗、部分入库都还是可用 |
| 已耗尽 | 台账剩余量 = 0，且入库量 = 0 |
| 已移交 | 台账剩余量 = 0，且入库量 > 0。台账剩余不再扣，请验改为扣关联容器；库存剩余继续跟物料库 |
| 已销毁 | 台账剩余被销毁 |

留样不单独占一个状态。

### 2.5 权限与入口

使用他人样品时，沿用来源注册对象的数据权限：创建人、所属部门是否可见、项目成员是否可见，以及对象上已有的分享范围。同项目、同部门能不能用，由这些设置决定。样品库不再做一层领用审批。

| 入口 | 结果 |
| --- | --- |
| 产物登记注册对象 | 自动生成样品台账，来源指向该对象和实验记录 |
| 从已有注册对象创建 | 生成一条台账 |
| 实验记录中使用样品 | 校验权限后扣可用量，写流水 |
| 台账上发起请验 | 请验单进入样品池。有台账剩余时可扣可用量；有关联库存时必须选择容器和使用量，并扣物料 |

## 3. 请验与入库（已拍板）

全部入库之后仍然从样品台账发起请验。样品台账和入库物料保持关联，请验时带出这份关联下剩余量大于 0 的容器。用户选择容器并填写使用量，物料库扣减对应容器，请验单记下样品、容器和使用量。

同一次请验可以只扣台账剩余、只扣容器，或两边都扣。两边各写各的流水，不把容器用量算进台账剩余。
