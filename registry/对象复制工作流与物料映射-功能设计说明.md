## 需求背景

在《Registry 科学数据注册》上补三类能力，一次配齐：

1. **对象复制（对象→对象）**：源对象已注册实体按映射生成目标对象新实体，解决模型字段不一致时的迁移/汇聚，并记录溯源。
2. **对象 ↔ 物料主数据**：实验产物对象与物料主数据有大量共用字段，两套模型不宜强行统一。在对象上配置映射，**ELN 产出入库同屏双建**时重叠字段只填一次，同时新建两侧。
3. **注册数据工作流**：对象可挂已有工作流。手动新增、对象复制、以及物料入库同步生成的对象实体，若目标对象开启工作流，均进「待审批」。

```
配置（对象模型 · 映射关系设置）
        │
        ├─ 对象模型映射 ──────────► Registry「复制到...」──► 目标对象新实体
        │                              │
        └─ 对象与物料信息映射 ──► ELN 产出入库（同屏双建）
                                      ├─ 重叠字段只填一次，按映射双写
                                      ├─ 同时新建对象实体 + 物料主数据
                                      └─ 批次/存放仍手填，不走映射
```

工作流挂在对象模型上，与映射配置独立；复制/同步落库时若目标对象开启工作流，再进入审批。

# 一、映射关系设置（配置态）

两类映射都配在**当前对象**上，物料类型侧不设入口。原型入口：对象模型列表「字段映射配置」（条数 + 编辑）。

## 1.1 映射列表

| **A、概述** |  |
| --- | --- |
| **功能模块 / 入口** | 配置中心-参数设置-数据模型设置-对象模型-映射关系设置 |
| **功能说明** | 同一对象可并存多套映射：对象模型映射（对象↔对象）与对象与物料信息映射（对象↔物料类型）。列表展示类型、映射对象、条数、备注、审计字段。 |
| **权限** | 公司管理员；对象编辑权限 |
| **B、功能点** |  |
| **功能点** | **描述** |
| 列表列 | 映射关系（类型标签）、映射对象、映射数量、备注、创建人/创建时间、修改人/修改时间、操作（设置 / 删除） |
| 映射对象文案 | 对象模型映射：`源对象：XXX → 当前对象`；物料映射：`物料类型：XXX` |
| 数量约束 | **对象模型映射**：多对一汇聚，一个目标可绑多个源，同源同目标至多一套。**物料映射**：一个对象可绑多个物料类型；**一个物料类型全局只能被一个对象绑定**，已被绑定的类型在其他对象上不可选 |
| 同公司 | 源对象 / 物料类型与当前对象必须同公司，跨公司不可选 |

| 新增 | 选映射关系类型；对象模型映射再选源对象；物料映射再选物料类型（须「已发布 + 启用」）。未选类型不可下一步 |
| 删除 | 二次确认。删除不影响已复制/已入库数据，但无法再按该规则复制或入库同步。对象删除约束不受映射影响 |
| 切换类型 | 设置弹窗内切换「对象模型映射 / 对象与物料信息映射」视为换表，未保存对应会丢失，需确认 |

## 1.2 字段对照弹窗（对齐原型）

| **功能点** | **描述** |
| --- | --- |
| 弹窗结构 | 第一行：映射关系下拉、备注。对照表表头与「名称 / 字段类型」同一灰底。<br>对象映射：左=源对象下拉（设计库/参考库），右=当前对象。<br>物料映射：左=当前对象（源字段），右=物料类型下拉（实验产物等）；右侧列出该物料类型全部可映射字段 |
| 对应规则 | **同一行即一对映射**。右侧列出**目标侧**全部可映射字段；左侧为该行选择源字段，可不设置。已占用的源字段不可再选（一对一） |
| 对象模型映射范围 | 右侧列出目标对象全部可写入字段。计算字段（关联查找/公式/汇总）不出现在右侧，目标端自算。下拉字段另配选项值子表（见 1.4）。关联字段按 1.5 |
| 物料映射范围 | **仅物料基础信息 + 扩展信息**。批次字段不出现在对照表。右侧是物料字段（物料类型名）；左侧是当前对象字段（Registry 类型） |
| 物料映射 · 计算字段 | **当前对象的关联查找 / 公式 / 汇总不能作为写入目标**（对照表不出现这些目标行，物料→对象时不写入）。**对象作为源时可以映射到物料的文本或数值**（基础信息文本/长文本/数值，扩展单行文本/计数器）。取源实体当时计算值；非文本/数值的物料行（列表/开关/上传等）中这些源字段禁用 |
| 两侧类型体系 | **不可混用**。对象侧：文本 / 数字 / 日期 / 下拉选择 / 勾选 / 附件 / 图片 / 关联 / 用户 / 部门。物料侧基础信息：文本 / 数值 / 列表 / 附件；扩展 11 种：单行文本 / 多行文本 / 计数器 / 滑块 / 开关按钮 / 时间选择框 / 单选框 / 下拉选择框 / 复选框 / 图片 / 上传。物料对照左列是对象类型、右列是物料类型。同名字段如浓度：左「数字」右「数值」 |
| 系统自动写入（物料） | 不占对照行：物料编号（规则生成，新增可改，不继承源编号）、注册数据（指向源对象实体）、计量单位/计量小数位（按物料类型带出） |
| 不可映射 | 物料侧化合物（老业务排除）；对象计算字段不可作为写入目标（见上，不是源侧一律排除） |
| 方向语义 | 配置在当前对象上。对象复制：左侧源对象 → 右侧当前对象。物料入库：对象→物料时按左侧对象字段（含计算字段）写入右侧物料文本/数值；物料→对象时不写入对象计算字段 |

## 1.3 字段类型兼容

### 对象 → 对象

| 目标字段类型 | 可接受源类型 | 处理方式 |
| --- | --- | --- |
| 文本 | 文本/数字/日期/下拉 | 转字符串 |
| 数字 | 数字 | 直接；文本需可转数值 |
| 日期 | 日期 | 按目标格式转换 |
| 下拉 | 下拉 | 选项值子表 |
| 关联 | 关联 | 见 1.5 |
| 用户/部门 | 用户/部门 | 直接搬 |
| 图片/附件 | 图片/附件 | 文件复制 |
| 关联查找/公式/汇总 | — | 不可映射，目标端自算 |

### 对象 ↔ 物料（基础信息）

| 物料侧类型 | 可接受的对象侧类型 | 处理方式 |
| --- | --- | --- |
| 文本/长文本 | 文本/数字/日期/下拉/关联查找/公式/汇总 | 转字符串 |
| 数值（浓度/纯度/含量等） | 数字；关联查找/公式/汇总（结果须可转数值） | 直接；失败按必填/非必填 |
| 列表（生产厂家等） | 下拉/文本 | 同名选项自动匹配，匹配不上留空 |
| 附件/图片 | 附件/图片 | 文件复制 |

### 对象 ↔ 物料（扩展字段 11 种）

| 物料扩展类型 | 可接受的对象侧类型 | 处理方式 |
| --- | --- | --- |
| 单行文本 | 文本/数字/日期/下拉/关联查找/公式/汇总 | 转字符串 |
| 多行文本 | 文本 | 转字符串（保留换行） |
| 计数器 | 数字；关联查找/公式/汇总（结果须可转数值） | 直接；过最小/最大/小数位 |
| 滑块 | 数字 | 直接；过区间 |
| 开关按钮 | 勾选 | 布尔直搬 |
| 时间选择框 | 日期 | 按目标格式 |
| 单选框/下拉选择框 | 下拉（单选） | 同名匹配，失败留空 |
| 复选框 | 下拉（多选） | 逐值同名；部分匹配只搬匹配项 |
| 图片 | 图片/附件 | 文件复制 |
| 上传 | 附件 | 文件复制 |

通用：复制/同步写入要过扩展字段校验与必填；**只读扩展字段允许系统写入**（只读约束表单手工编辑，不约束初始化）；字典变更后老数据不清空，新数据按最新选项文字匹配。反向（物料→对象）对称构造，但**不写入对象计算字段**。对象计算字段作为源时，仅可写入物料文本/长文本/数值（及扩展单行文本/计数器）。

## 1.4 选项映射

| 场景 | 规则 |
| --- | --- |
| 对象↔对象，下拉字段 | 该行展开「源选项 → 目标选项」子表；未指定的源选项复制时留空（必填则阻断） |
| 对象↔物料，列表/单选/下拉/复选 | **不做子表**。同名自动匹配，匹配不上留空（必填则阻断）。字典来源按当前字典；固定选项按固定项 |

## 1.5 关联字段（仅对象模型映射）

1. 源关联指向对象 X、目标关联指向对象 Y：复制时若已配 X→Y 映射则递归复制被关联实体；未配则该关联留空，不阻断。
2. X=Y：直接沿用源关联值。

物料映射不含批次里的父细胞/关联质粒等关联，不走本节。

# 三、对象 ↔ 物料（物料入库同步）

配置来自「对象与物料信息映射」。**运行时不从对象列表/物料主数据列表做「复制到物料」「复制到对象」**，统一由**物料入库页面**按映射同步。

## 3.1 关系与职责

| 项 | 约定 |
| --- | --- |
| **主路径** | **同屏双建**：实验员合成完成后，在 ELN 产出入库一次提交，**同时新建**对象实体 + 物料主数据 + 预入库批次。映射是字段对齐，不是从已有对象复制 |
| 次路径 | 已有对象、只新建物料/批次 — **本期不做** |
| 触发 | 选中物料类型且该类型已绑定对象物料映射 → 双建表单；提交时按对照双写 |
| 映射用什么 | 该物料类型全局唯一绑定的那套「对象 ↔ 物料类型」对照 |
| 映射写什么 | 仅两侧 **基础信息 + 扩展信息** 中已配对的字段 |
| 映射不写什么 | 批次信息（批号、有效期、父细胞、COA、供应商等）仍在入库页填写 |
| 未配映射 | 仅物料入库，弱提示，不拦截，不建对象 |
| 前置 | 同公司；物料类型「已发布 + 启用」 |

## 3.2 同步时的系统写入与判重

| **功能点** | **描述** |
| --- | --- |
| 物料编号 | 新建主数据时按规则生成，允许改；不继承对象编号 |
| 注册数据 | 物料类型开启该字段时，写入指向对象实体；编号参与主数据唯一性校验（既有行为）；物料名称同步为「编号 (名称)」（既有行为） |
| 计量 | 单位/小数位按物料类型带出 |
| 主数据状态 | 新建默认「启用」 |
| 只读扩展字段 | 允许系统写入 |
| 判重 | 双建时命中唯一性 → **整单阻断**，两侧都不建。不自动引用已有主数据（避免只建对象不建物料）。提示已有主数据编号 |
| 批次对应 | 批次字段走入库链路，不走映射。批次号由用户填，不默认等于对象编号 |

## 3.3 溯源（注册数据锚点）

不新建「来源关联」。对象↔物料靠物料主数据「注册数据」指向对象实体（物料类型需开启该字段；未开启则只靠业务字段）。

| **功能点** | **描述** |
| --- | --- |
| 物料侧 | 详情查看注册数据时显示对象标签，hover 摘要（既有） |
| 对象侧 | 「关联物料」tab 显示库存（容器号、批次、剩余量等，既有） |
| 语义 | 源对象变更不自动改主数据；主数据变更不反向改对象 |

## 3.4 入库页（同屏双建）

不另开「复制到物料 / 复制到对象」。ELN 抽屉分区、字段出现规则、失败处理以 [ELN-实验产出入库-功能说明.md](../eln/ELN-实验产出入库-功能说明.md) **第 10 节**为准。要点：

| 项 | 约定 |
| --- | --- |
| 一张表 | 不要「对象卡 + 物料卡」。抬头 → 共用信息 → 未映射对象/物料 → 批次 → 存放 |
| 重叠字段 | 已映射对照 **只出现一次**；主标签用物料字段名；写入两侧 |
| 未映射必填 | 仍要采集，分列对象信息 / 物料其他信息 |
| 系统写入 | 物料编号、对象编号、计量单位、注册数据（指向本次新建对象）不占对照行 |
| 工作流 | 入库生成的对象可进待审批；**本次**注册数据允许指向该待审批对象 |
| 预入库登记 | 库管侧仍不可改实验产物物料信息；映射执行只发生在 ELN 确认入库，不上架环节重跑 |

# 四、注册数据工作流

与映射配置独立，挂在对象模型上。

## 4.1 设置

| **功能点** | **描述** |
| --- | --- |
| 开关 | 对象设置「是否开启工作流」，默认关。关闭则按原流程直接「有效」 |
| 挂载 | 开启后从系统已有工作流**单选**一个。Registry 不定义工作流 |
| 走审批的入口 | 1. 手动新增注册 2. 对象复制入库 3. **物料入库同屏双建生成的对象实体**。导入、ELN 实验正文里直接注册对象视为已确认，不进临时态。双建时物料「注册数据」允许指向本次待审批对象，仅此事务例外 |

## 4.2 临时编号与状态

临时编号：`前缀 + 年月日 + 3 位流水`（如 ABC-20260914-001），按天重置。审批通过后按对象名称规则赋正式编号，不继承临时编号。临时编号转正后只留操作日志，页面不展示。

待审批/审批中禁止被引用、不参与关联查找/汇总、不能被实验引用。因此子项引用时父项必为有效。

| 状态 | 修改 | 删除 | 可被引用 | 编号 |
| --- | --- | --- | --- | --- |
| 待审批 | ✅ | ✅ | ❌ | 临时 |
| 审批中 | ❌ | ❌ | ❌ | 临时 |
| 有效 | ✅ | ✅ | ✅ | 正式 |
| 停用 | — | — | — | 正式（沿用） |

```
新增 / 对象复制 / 入库同步生成对象（开启工作流）
   │ 临时编号
   ▼
[待审批] ──可改──► 仍待审批
   │ 发起审批                 │ 关工作流：可直接转有效
   ▼                        │ 换工作流：按新流程重提
[审批中] ──驳回──► [待审批] ◄── 撤回
   │ 通过 → 正式编号
   ▼
[有效] ⇄ [停用]
```

## 4.3 审批与可见性

| **功能点** | **描述** |
| --- | --- |
| 可见性 | 待审批/审批中：创建人可见，他人隐藏，管理授权权限人可见。转正后按原可见范围 |
| 提交 | 待审批点「发起审批」→ 审批中，锁定 |
| 驳回/撤回 | 驳回或撤回 → 待审批，可改后重提或删除 |
| 通过 | 赋正式编号，转有效 |
| 转正后编辑 | 不再审批 |
| 批量 | 多条临时数据逐条独立审批 |

## 4.4 工作流变更与各模块

| 场景 | 处理 |
| --- | --- |
| 关闭 | 存量待审批：可走原流程重提，或直接转有效 |
| 更换 | 存量待审批：按新工作流重提 |
| 变更时审批中 | 须完成当前流程或先撤回 |
| 存量有效 | 不受对象后来开启工作流影响 |

| 模块 | 临时/审批中 |
| --- | --- |
| 列表/详情 | 按可见性；按钮按状态矩阵 |
| 关联查找/汇总/公式 | 不纳入计算 |
| 实体关系图 | 仅创建人及授权人可见，他人占位 |
| 引用关系 | 不显示（不可被引用） |
| 对象复制源 | 仅有效可作源 |
| 导入导出 | 导出含临时（按可见性）；导入不走审批 |
| ELN/样品 | 不可引用临时/审批中 |

# 五、校验策略汇总

| 场景 | 处理 |
| --- | --- |
| 必填未映射且未补录 | 阻断 |
| 非必填未映射/转换失败 | 留空 |
| 对象下拉选项未配对应 | 留空（必填阻断） |
| 物料选项同名匹配失败 | 留空（必填阻断）；复选部分匹配只搬匹配项 |
| 关联未配 X→Y | 该关联留空，不阻断 |
| 计算字段（物料映射） | 不写入对象计算字段。对象→物料：计算字段可映到文本/数值，取当时计算值；转失败留空（必填阻断） |
| 跨公司 | 禁止配置与执行 |
| 物料类型未发布/禁用 | 禁止入库同步 |
| 命中主数据唯一性（双建） | 整单阻断，两侧都不建 |
| 目标对象开启工作流（对象复制或入库生成对象） | 待审批 |
| 化合物（物料老字段） | 不映射 |
| 批次字段 | 不映射，入库页录入 |
