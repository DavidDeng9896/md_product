# 对象复制功能 — 设计说明

> 基于《Registry 科学数据注册》需求文档，新增"对象复制"功能：把源对象已注册的实体数据，按映射规则复制为目标对象下的新实体，并记录溯源关系。
>
> 状态：逻辑主干与交互细节均已确认闭环（2026-09-11 定稿）。

## 1. 功能概述

将源对象下已注册的实体数据，复制到目标对象下生成新实体。因源/目标两个对象模型字段不一致，需在目标对象上预先配置字段映射关系。复制产生的目标实体：

- 按目标对象自身名称规则生成新编号/名称（不继承源）
- 通过内置"来源关联"字段记录溯源（可回溯，但数据独立、源变更不影响目标）
- 每次复制均新建，不做更新/同步

## 2. 核心概念

| 概念     | 说明                          |
| ------ | --------------------------- |
| 源对象    | 被复制数据的来源对象                  |
| 目标对象   | 接收复制数据、在其上配置映射的对象           |
| 映射配置   | 在目标对象上配置的"源字段→目标字段"对应关系     |
| 来源关联字段 | 目标对象内置的系统级关联字段，承接复制来源，指向源实体 |

## 3. 架构决策（已确认）

1. **多对一汇聚**：一个目标对象可绑定多个源对象，每个源一套独立字段映射
2. **单源单映射**：同一源对象在同一目标对象上至多一套映射规则（避免复制时不知套哪套）
3. **目标按新规则重新编号**：复制出的实体视为目标对象的新注册实体，走目标名称规则（前缀+固定字符+父项+流水号）生成编号
4. **纯新建、不更新**：每次复制都新建目标实体；重复复制=多条；源变更不影响已复制目标；溯源仅回溯，不承载同步语义
5. **源侧推送入口**：在源实体详情/列表触发"复制到..."，系统按已配映射列出可选目标对象
6. **溯源走内置来源关联字段**：系统级，不显示在对象模型字段配置界面，由复制功能自动写入
7. **关联递归映射**：源关联指向对象 X、目标关联指向对象 Y，需 X→Y 存在映射配置才递归复制被关联实体；未配映射=不接收=该关联留空，不阻断整批
8. **选项值映射**：下拉字段做选项值对值映射（子表）
9. **计算字段跳过**：关联查找/公式/汇总为计算字段，复制时跳过，目标端自动算
10. **必填项**：提交校验时，必填项为空则阻断；非必填字段映射不上则留空
11. **同公司前置约束**：源对象与目标对象所属公司必须一致；跨公司不允许配置映射、不允许复制（数据隔离 / 合规）
12. **确认弹窗基础信息继承**：部门、项目默认继承源实体值；其他基础信息（分享人、可见范围、别名等）默认也继承源值，但均可手填修改
13. **批量复制**：支持列表勾选多个源实体一次性复制到同一目标，逐条弹确认弹窗、逐条落库

## 4. 映射配置

### 4.1 配置位置与入口

- 配置在**目标对象**上进行（接收方定义 ingestion 规则）
- 在目标对象的设置中新增"数据映射"配置项

### 4.2 配置内容

一份完整的映射配置包含：

- **源对象绑定**：选择一个源对象，必须与目标对象是同一个公司下的源对象
- **字段映射表**：目标字段 ← 源字段，逐行配置
- **选项映射子表**：当下拉字段参与映射时，展开源选项→目标选项的值对应
- **关联递归声明**：关联字段映射时，声明被关联对象 X→Y 的映射关系（沿用 X→Y 已配置的映射；未配则该关联留空）

### 4.3 字段类型映射兼容规则

| 目标字段类型     | 可接受源类型      | 处理方式                                      |
| ---------- | ----------- | ----------------------------------------- |
| 文本         | 文本/数字/日期/下拉 | 转字符串                                      |
| 数字         | 数字          | 直接；文本需校验可转数值                              |
| 日期         | 日期          | 按目标格式转换                                   |
| 下拉         | 下拉          | 选项值对值映射                                   |
| 关联         | 关联          | 递归映射被关联对象实体；未配 X→Y 则留空;其中关联字段目标和源的关联对象要一致 |
| 用户/部门      | 用户/部门       | 直接搬                                       |
| 图片/附件      | 图片/附件       | 文件复制                                      |
| 关联查找/公式/汇总 | —           | 不可映射，跳过（目标自动算）                            |

## 5. 复制流程

### 5.1 触发

源实体详情/列表 → "复制到..." → 系统按该源对象已配的映射，列出可选的目标对象 → 用户选择目标。

### 5.2 确认弹窗（关键交互）

复制非静默执行，弹出类似"手动注册"的新增弹窗，预填映射后的内容：

- **映射数据**：只读，不可改
- **基础信息**：默认继承源实体值（部门、项目默认继承；分享人、可见范围、别名等也继承），均可手填修改
- **未匹配/缺失字段**：用户在弹窗里手动补充
- **提交校验**：必填项（=关键项）为空则阻断提交；非必填缺失则留空

### 5.3 批量复制（本期不做）

1. 源对象列表勾选多个实体 → 点击"复制到..."选择目标对象
2. 逐条弹出确认弹窗（同 5.2），逐条确认、逐条落库
3. 每条实体独立走名称规则生成新编号，独立校验；某条失败不影响其他条，完成后汇总报告成功/失败明细

### 5.4 落库

- 按目标对象名称规则生成新编号/名称
- 写入映射数据 + 用户补充/修改的内容
- 自动写入"来源关联"字段，指向源实体（+复制时间/操作人）
- 关联字段按递归映射结果写入；未映射的关联留空

## 6. 溯源机制

- 目标对象内置系统级"来源关联"字段（关联对象类型），指向源实体
- 不显示在对象模型字段配置界面（用户配不了、字段列表看不到）
- 由复制功能自动写入
- 复用关联字段能力：来源实体在详情/列表以标签显示，hover 弹出源实体基础信息，点击跳转
- **实体详情显示来源标签**（已确认显示；仅"对象设置"隐藏该字段的配置入口）
- **不承载更新语义**：源变更不自动同步，不提供"重新同步覆盖"操作

## 7. 校验策略汇总

| 场景                    | 处理           |
| --------------------- | ------------ |
| 必填项（关键项）映射不上且用户未在弹窗补充 | 提交时阻断        |
| 非必填字段映射不上/转换失败        | 留空，不阻断       |
| 关联字段未配 X→Y 映射         | 该关联留空，不阻断    |
| 计算字段（关联查找/公式/汇总）      | 跳过，目标自动算     |
| 类型转换（如文本→数字）失败        | 按必填与否决定阻断/留空 |

## 8. 交互细节确认（2026-09-11 定稿）

| 项              | 结论                                          |
| -------------- | ------------------------------------------- |
| 来源在实体详情是否显示    | **显示**来源标签（仅"对象设置"隐藏该字段的配置入口）               |
| 确认弹窗"可改字段"完整清单 | 部门、项目默认继承源值；分享人、可见范围、别名等也默认继承，均可手填修改；映射数据只读 |
| 批量复制           | **支持**：列表勾选多实体 → 批量复制到目标 → 逐条确认弹窗 → 逐条落库    |
