## 需求背景

在《Registry 科学数据注册》与《资源管理需求说明》两大体系之间，存在数据重复录入问题：

1. **共用字段重复填写**：实验产物对象创建时，需同步录入样品物料/库存相关信息；对象侧与物料主数据侧存在大量共用字段（名称、浓度、纯度、厂家等），两边各录一遍，操作繁琐且易错。
2. **统一模型代价不可接受**：对象模型与物料主数据模型分属两套体系（对象字段动态建模 vs 物料类型配置驱动），强行统一涉及物料主数据侧大量改造。

**解法**：将已确认的对象复制映射机制从"对象→对象"扩展到"对象↔物料主数据"，在对象上配置映射，实现两侧数据一键复制互通。

**关键决策已全部确认闭环（2026-09-14/15 四轮讨论）**，详见《对象复制映射扩展-设计讨论.md》。

# 一、映射配置设置

## 1.1 配置入口与映射类型

| **A、概述** |  |
| --- | --- |
| **功能编号** |  |
| **功能模块**<br>**访问入口** | 配置中心-参数设置-数据模型设置-对象模型-映射关系设置 |
| **功能说明** | 对象的映射关系设置中并存两类映射：<br>1. **对象模型映射**（对象↔对象，原对象复制功能，本文档不展开）<br>2. **对象与物料信息映射**（对象↔物料主数据，本功能）<br>对象与物料类型之间可建立复制映射，实现对象实体与物料主数据的双向复制。 |
| **权限** | 公司管理员权限；对象编辑权限 |
| **B、功能点** |  |
| **功能点** | **描述** |
| 映射列表 | 1. 在对象设置中显示当前对象已配置的物料映射列表：物料类型名称、业务类型、字段映射条数、创建人/创建时间、修改人/修改时间<br>2. 一个对象可配置多个不同物料类型的映射；**一个物料类型只能被一个对象的映射绑定**（物料类型侧 1:1 全局唯一），已被绑定的物料类型在其他对象上不可再选 |
| 新增映射 | 1. 点击新增，选择物料类型：<br>　1) 物料类型与对象必须属于同一公司，跨公司不可选<br>　2) 物料类型须处于"已发布 + 启用"状态<br>　3) 支持搜索选择<br>2. 选择后进入字段映射配置 |
| 字段映射表 | 1. 逐行配置"物料字段 ← 对象字段"对应关系<br>2. **映射范围：仅基础信息 + 扩展信息**。批次信息字段（批号、有效期至、父细胞、序列图谱、检测状态、来源实验、COA、供应商、货号等）全部不参与映射——批次内容在产物入库/预入库登记环节录入，不属于主数据复制职责<br>3. 目标字段展示物料类型的可映射字段（基础信息 + 扩展信息），源字段下拉展示对象的对应兼容类型字段（见 1.2）<br>4. 不可映射字段置灰不可选：化合物（老业务，新业务对象侧已支持化合物类型）、批次字段、计算字段（对象侧关联查找/公式/汇总） |
| 系统自动写入项 | 以下字段不作为映射行配置，由系统在复制时自动处理：<br>1. **物料编号**：按编号规则自动生成，新增时支持修改，不继承源对象编号<br>2. **注册数据**：复制时自动写入，指向源对象实体（见第三章）<br>3. **计量单位/计量小数位**：物料类型已配置则自动带出 |
| 选项匹配规则 | 1. 选项类字段（列表、单选框、下拉选择框、复选框）与对象下拉字段映射时，**按同名选项自动匹配；不可匹配的值留空**（必填项则阻断，用户在弹窗补充）<br>2. 选项来源两种：扩展字段关联数据源（通用配置字典）按字典当前选项匹配；手动行数据（固定选项）按固定选项匹配<br>3. 复选框（多选）逐值匹配，部分匹配仅搬匹配项 |
| 编辑/删除 | 1. 映射支持编辑、删除，删除需二次确认<br>2. 删除映射不影响已复制生成的主数据/对象实体 |

## 1.2 字段类型映射兼容规则（对象 → 物料主数据）

**基础信息字段**：

| 物料侧字段类型 | 可接受的对象侧类型 | 处理方式 |
| --- | --- | --- |
| 文本/长文本 | 文本/数字/日期/下拉 | 转字符串 |
| 数值（浓度/纯度/含量等） | 数字 | 直接；文本需校验可转数值 |
| 列表（生产厂家等） | 下拉/文本 | 同名选项自动匹配 + 不可匹配留空 |
| 附件/图片 | 附件/图片 | 文件复制 |

**扩展字段（11 种类型，依据《物料类型扩展字段配置 PRD》）**：

| 物料扩展字段类型 | 可接受的对象侧类型 | 处理方式 |
| --- | --- | --- |
| 单行文本 | 文本/数字/日期/下拉 | 转字符串 |
| 多行文本 | 文本 | 转字符串（换行保留） |
| 计数器 | 数字 | 直接；需满足最小值/最大值/小数位校验 |
| 滑块 | 数字 | 直接；需满足区间校验 |
| 开关按钮 | 勾选 | 布尔直搬 |
| 时间选择框 | 日期 | 按目标格式转换 |
| 单选框/下拉选择框 | 下拉（单选） | 同名选项自动匹配 + 不可匹配留空 |
| 复选框 | 下拉（多选） | 逐值同名匹配；部分匹配仅搬匹配项 |
| 图片 | 图片/附件 | 文件复制（图片格式） |
| 上传 | 附件 | 文件复制（多文件支持） |

**通用规则**：

1. 复制写入需过扩展字段的校验条件（最大长度、正则、数值区间、步长等）与必填项约束
2. **只读扩展字段允许系统写入**：物料扩展字段"是否只读"约束的是表单交互层（防用户手动编辑）；对象复制属于新增初始化场景，系统写入不受只读限制
3. **字典变更兼容**：扩展字段关联数据源（字典）变更后，既有主数据历史取值不清空（沿用既有约束）；复制新增的数据按最新字典选项进行文字匹配
4. 物料侧不可映射：化合物（老业务排除）、全部批次信息字段
5. 对象侧不可映射：计算字段（关联查找/公式/汇总，目标端自动计算）

（反向"物料主数据 → 对象"的兼容矩阵对称构造，方向相反）

# 二、复制功能

## 2.1 对象 → 物料主数据

| **A、概述** |  |
| --- | --- |
| **功能编号** |  |
| **功能模块**<br>**访问入口** | Registry-科学数据注册-对象列表/对象详情 |
| **功能说明** | 在对象实体一侧发起复制，按已配置的映射在目标物料类型下生成物料主数据，消除两侧共用字段的重复录入。支持单条与批量。 |
| **权限** | 对象查看权限；物料主数据新增权限 |
| **B、功能点** |  |
| **功能点** | **描述** |
| 复制入口 | 1. 对象详情"更多"菜单、列表行操作中显示"复制到物料..."<br>2. 列表勾选多实体支持批量复制，逐条确认、逐条落库，逐条独立校验 |
| 目标选择 | 1. 弹窗列出与对象存在映射配置的物料类型（同公司）<br>2. 显示物料类型名称、业务类型，支持搜索 |
| 确认弹窗 | 1. 弹窗形式类似"主数据新增"，预填映射转换后的内容<br>2. **映射数据只读**；未映射/匹配失败的目标必填字段高亮提示，用户在弹窗内补充<br>3. 物料名称按现有"注册数据"规则同步为"编号 (名称)"格式（对象选择注册数据后的既有行为）<br>4. 弹窗可改项的完整定义**留待原型设计阶段确定** |
| 提交校验 | 1. 必填项为空则阻断提交；非必填字段映射不上/转换失败留空，不阻断<br>2. 校验物料类型处于"已发布 + 启用"状态 |
| **判重与自动复用** | 1. 复制提交时按物料类型配置的"主数据唯一性校验"（可多字段组合判定）进行判重<br>2. **命中唯一性校验 → 不新建主数据，该入库物料直接引用已有主数据**，系统自动挂接，用户无需手动操作<br>3. 源对象实体不受影响 |
| 落库 | 1. 物料编号按编号规则自动生成（新增时可修改，不继承源对象编号）<br>2. 写入映射数据 + 用户补充/修改的内容；只读扩展字段允许系统写入<br>3. 自动写入"注册数据"字段指向源对象实体（见第三章）<br>4. 主数据初始状态默认"**启用**"<br>5. 计量单位/计量小数位按物料类型配置自动带出 |

## 2.2 物料主数据 → 对象

| **A、概述** |  |
| --- | --- |
| **功能编号** |  |
| **功能模块**<br>**访问入口** | Inventory-物料配置-物料主数据（入口形式随原型阶段确定） |
| **功能说明** | 在物料主数据一侧发起复制，按已配置的映射在目标对象下生成新注册实体。 |

# 三、溯源机制（注册数据锚点）

| **A、概述** |  |
| --- | --- |
| **功能编号** |  |
| **功能模块**<br>**访问入口** | 物料主数据详情 / Registry 对象详情 |
| **功能说明** | 对象→主数据复制时，系统自动写入物料主数据"注册数据"字段指向源对象实体，实现两侧对应关系。复用《Registry 科学数据注册》既有"注册数据/关联物料"能力，不新建溯源字段。 |
| **权限** | 对象查看权限；物料主数据查看权限 |
| **B、功能点** |  |
| **功能点** | **描述** |
| 写入规则 | 1. 复制生成主数据时，自动写入"注册数据"字段指向源对象实体（需物料类型开启该字段；未开启则不写入，对应关系仅靠业务字段）<br>2. 注册数据编号参与主数据唯一性校验（既有行为）<br>3. 物料名称同步为"编号 (名称)"格式（既有行为） |
| 侧向对应 | 批号与源对象编号保持一致（入库场景下批次内容沿用产物入库链路录入） |
| 溯源展示 | 1. 物料主数据详情/物料详情中查看"注册数据"时显示注册对象标签，hover 显示对象基础信息（既有行为）<br>2. Registry 对象详情"关联物料"tab 显示关联物料的库存信息（容器号、批次、剩余量等，既有行为） |
| 语义约束 | 不承载更新/同步语义：源对象后续变更不自动同步主数据；主数据变更不反向同步对象 |

# 四、校验策略汇总

| 场景 | 处理 |
| --- | --- |
| 必填项映射不上且用户未在弹窗补充 | 提交时阻断 |
| 非必填字段映射不上/转换失败 | 留空，不阻断 |
| 选项值同名匹配失败 | 留空（必填则阻断）；复选框部分匹配仅搬匹配项 |
| 类型转换（如文本→数值）失败 | 按必填与否决定阻断/留空 |
| 计算字段（关联查找/公式/汇总） | 跳过，目标端自动算 |
| 化合物字段 | 不可映射（老业务排除） |
| 批次信息字段 | 不在映射范围（批次内容走入库登记链路） |
| 复制提交命中主数据唯一性校验 | **不新建，直接引用已有主数据**（自动复用） |
| 物料类型未发布/禁用 | 禁止复制（前置校验，与手动新增主数据一致） |
| 源/目标跨公司 | 映射配置与复制均禁止 |
| 目标对象开启工作流（主数据→对象） | 进入"待审批"，走对象工作流规则 |

# 五、与既有功能的衔接

| 模块 | 衔接说明 |
| --- | --- |
| 对象复制（对象↔对象） | 映射配置入口统一在对象的映射关系设置中，两类映射并存互不影响 |
| 注册数据工作流 | 主数据→对象复制入库进"待审批"，逐条独立审批，规则完全一致 |
| 物料主数据手动新增 | 复制生成的主数据与手动新增行为一致：编号自动生成可改、唯一性校验、启用/禁用状态管理 |
| 物料类型版本管理 | 物料类型配置更新版本后，已复制生成的主数据沿用既有"物料类型配置已更新，是否更新到最新"提示逻辑 |
| 关联物料 tab（Registry） | 通过注册数据锚点关联的物料，在对象详情"关联物料"tab 显示库存信息（既有能力） |
| 主数据导入导出 | 复制生成的主数据与导入数据同等参与导出；不受影响 |
