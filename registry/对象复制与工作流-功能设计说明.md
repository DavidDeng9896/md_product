## 需求背景

在《Registry 科学数据注册》基础上新增两个功能：

1. **对象复制**：源对象已注册的实体数据，按映射规则复制为目标对象下的新实体，解决两个对象模型字段不一致时的数据迁移/汇聚问题，并记录溯源关系。
2. **注册数据工作流**：对象模型可开启工作流，开启后新增/复制入库的数据先进"待审批"临时状态（临时编号），审批通过后赋正式编号转正，保证入库数据质量。

两个功能的衔接：复制产生的新实体，若目标对象开启了工作流，同样进入审批流程。

# 一、对象复制功能

## 1.1 数据映射设置

| **A、概述** |  |
| --- | --- |
| **功能编号** |  |
| **功能模块**<br>**访问入口** | 配置中心-参数设置-数据模型设置-对象模型-数据映射 |
| **功能说明** | 在目标（接收）对象上配置与源对象之间的字段映射关系。因源/目标两个对象模型字段不一致，复制时按映射规则完成源字段值到目标字段值的转换。一个目标对象可绑定多个源对象（多对一汇聚），每个源对象至多一套映射（单源单映射）。 |
| **权限** | 公司管理员权限；对象编辑权限 |
| **B、功能点** |  |
| **功能点** | **描述** |
| 映射列表 | 1. 在对象设置中显示当前对象已配置的映射规则列表：源对象名称、源对象类型、字段映射条数、创建人/创建时间、修改人/修改时间<br>2. 同一源对象在当前目标对象下至多一条映射，已配置的源对象在选择时不可重复选 |
| 新增映射 | 1. 点击新增，选择源对象：<br>　1) 源对象与目标对象必须属于同一公司，跨公司源对象不可选（数据隔离前置约束）<br>　2) 支持搜索选择<br>2. 选择后进入字段映射配置 |
| 字段映射表 | 1. 逐行配置"目标字段 ← 源字段"对应关系<br>2. 目标字段展示目标对象全部可映射字段，源字段下拉展示源对象的对应兼容类型字段（见 1.2 兼容规则）<br>3. 未映射的目标字段保持为空，复制时用户可在确认弹窗中补充<br>4. 计算字段（关联查找、公式、汇总）不可映射，置灰不可选 |
| 选项映射子表 | 1. 当下拉字段参与映射时，该行展开"源选项 → 目标选项"的值对应子表<br>2. 源选项列出源字段全部选项，用户逐个指定对应的目标选项<br>3. 未指定对应的源选项，复制时该值留空（必填项则阻断，见 1.5） |
| 关联字段映射 | 1. 源关联字段指向对象 X、目标关联字段指向对象 Y 时，复制时按 X→Y 的映射递归复制被关联实体<br>2. X→Y 未配置映射 = 不接收，该关联留空，不阻断复制<br>3. 若目标与源的关联指向同一对象（X=Y），直接沿用源关联值 |
| 编辑/删除 | 1. 映射支持编辑、删除，删除需二次确认<br>2. 对象被删除约束不受映射影响；删除映射不影响已复制生成的目标实体 |

## 1.2 字段类型映射兼容规则

| 目标字段类型 | 可接受源类型 | 处理方式 |
| --- | --- | --- |
| 文本 | 文本/数字/日期/下拉 | 转字符串 |
| 数字 | 数字 | 直接；文本需校验可转数值 |
| 日期 | 日期 | 按目标格式转换 |
| 下拉 | 下拉 | 选项值对值映射（子表） |
| 关联 | 关联 | 递归映射被关联对象实体；未配 X→Y 则留空 |
| 用户/部门 | 用户/部门 | 直接搬 |
| 图片/附件 | 图片/附件 | 文件复制 |
| 关联查找/公式/汇总 | — | 不可映射（计算字段，目标端自动计算） |

## 1.3 复制到（源侧入口）

| **A、概述** |  |
| --- | --- |
| **功能编号** |  |
| **功能模块**<br>**访问入口** | Registry-科学数据注册-对象列表/对象详情 |
| **功能说明** | 在源实体一侧发起复制。系统按源对象已配置的映射列出可选目标对象，用户选择后经确认弹窗完成复制。支持单条复制与批量复制。 |
| **权限** | 源对象查看权限；目标对象新增权限 |
| **B、功能点** |  |
| **功能点** | **描述** |
| 单条复制入口 | 1. 对象详情"更多"菜单、列表行操作中显示"复制到..."<br>2. 仅"有效"状态的实体可发起复制（待审批/审批中/停用不可作为复制源） |
| 批量复制入口 | 1. 列表勾选多个实体 → "复制到..."<br>2. 逐条弹出确认弹窗、逐条落库；每条独立生成编号、独立校验，某条失败不影响其他条，完成后汇总成功/失败明细 |
| 目标对象选择 | 1. 弹窗列出与源对象存在映射配置的目标对象（同公司）<br>2. 显示目标对象名称、对象类型、图标，支持搜索 |
| 确认弹窗 | 1. 弹窗形式同"手动注册"弹窗，预填映射转换后的内容<br>2. **映射数据只读**，不可修改<br>3. **基础信息默认继承源实体值**：部门、项目默认继承；分享人、可见范围、别名等也默认继承，**均可手填修改**<br>4. 映射不上的目标必填字段高亮提示，用户在弹窗内补充<br>5. 序列类对象（氨基酸/DNA/RNA）复制序列内容；化合物对象复制结构数据 |
| 提交校验 | 1. 必填项（=关键项）为空则阻断提交<br>2. 非必填字段映射不上/转换失败则留空，不阻断 |
| 落库 | 1. 按目标对象名称规则生成新编号/名称（不继承源编号）<br>2. 写入映射数据 + 用户补充/修改的内容<br>3. 自动写入"来源关联"字段指向源实体（见 1.4）<br>4. 目标对象开启工作流时，落库后进入待审批状态（见 2.2） |
| 复制后关系 | 1. 每次复制均新建实体，重复复制 = 多条目标实体<br>2. 源实体后续变更不影响已复制目标；溯源仅回溯，无同步语义 |

## 1.4 来源关联（溯源）

| **A、概述** |  |
| --- | --- |
| **功能编号** |  |
| **功能模块**<br>**访问入口** | Registry-科学数据注册-对象详情（目标实体） |
| **功能说明** | 目标对象内置系统级"来源关联"字段，承接复制来源，指向源实体。系统自动写入，用户不可配置。 |
| **权限** | 对象查看权限 |
| **B、功能点** |  |
| **功能点** | **描述** |
| 字段定义 | 1. 系统内置的"来源关联"字段（关联对象类型），指向复制来源的源实体<br>2. 由复制功能自动写入，同时记录复制时间、操作人 |
| 显示规则 | 1. **实体详情显示来源标签**，复用关联字段标签能力：hover 显示源实体基础信息气泡，点击跳转源实体详情<br>2. 仅"对象模型设置"中隐藏该字段的配置入口（用户不可见、不可配、不可删） |
| 语义约束 | 1. 不承载更新/同步语义：源变更不自动同步目标，不提供"重新同步"操作<br>2. 与工作流审批不冲突 |

## 1.5 校验策略汇总

| 场景 | 处理 |
| --- | --- |
| 必填项映射不上且用户未在弹窗补充 | 提交时阻断 |
| 非必填字段映射不上/转换失败 | 留空，不阻断 |
| 关联字段未配 X→Y 映射 | 该关联留空，不阻断 |
| 计算字段（关联查找/公式/汇总） | 跳过，目标自动算 |
| 类型转换（如文本→数字）失败 | 按必填与否决定阻断/留空 |
| 源/目标跨公司 | 映射配置与复制均禁止 |

# 二、注册数据工作流

## 2.1 对象工作流设置

| **A、概述** |  |
| --- | --- |
| **功能编号** |  |
| **功能模块**<br>**访问入口** | 配置中心-参数设置-数据模型设置-对象模型 |
| **功能说明** | 对象模型设置中新增"注册数据工作流"配置。开启后该对象的注册数据（新增/复制入库）需经审批，审批通过后方可转正。 |
| **权限** | 公司管理员权限；对象编辑权限 |
| **B、功能点** |  |
| **功能点** | **描述** |
| 工作流开关 | 1. 对象设置新增"是否开启工作流"开关，默认关闭<br>2. 关闭时对象数据按原流程直接入库为"有效" |
| 挂载工作流 | 1. 开启后显示工作流选择，从系统已有的工作流列表中**单选一个**挂载<br>2. 支持搜索选择；Registry 不提供工作流定义能力，仅挂载 |
| 审批范围 | 仅以下两个入库入口走审批：<br>1. 手动新增注册<br>2. 对象复制入库<br>导入、ELN 实验注册等其他入口视为已确认数据，不入临时状态 |

## 2.2 临时入库与编号

| **A、概述** |  |
| --- | --- |
| **功能编号** |  |
| **功能模块**<br>**访问入口** | Registry-科学数据注册-对象列表/对象详情 |
| **功能说明** | 开启工作流的对象，新增/复制的数据入库时默认"待审批"状态，使用临时编号；审批通过后赋正式对象编号。 |
| **权限** | 对象查看权限；可见性规则见 2.4 |
| **B、功能点** |  |
| **功能点** | **描述** |
| 临时编号 | 1. 规则：**前缀 + 年月日 + 3 位流水**（如 ABC-20260914-001）<br>2. 流水按天重置，每天从 001 重新计数<br>3. 审批通过后由系统按对象名称规则（前缀+固定字符+父项+流水号）赋予正式编号，**不继承临时编号** |
| 临时编号留痕 | 临时编号在转正后保留于操作日志留痕，页面上不体现（不在实体字段/详情展示） |
| 编号与引用 | 1. 待审批/审批中的实体禁止被其他对象数据引用、不参与关联查找/汇总计算、不能被实验引用<br>2. 因此子项引用父项时父项必为"有效"（已持正式编号），正式编号生成不受影响 |

## 2.3 状态体系与权限矩阵

| 状态 | 修改 | 删除 | 可被关联引用 | 编号 |
| --- | --- | --- | --- | --- |
| 待审批 | ✅ 可修改 | ✅ 可删除 | ❌ | 临时编号 |
| 审批中 | ❌ | ❌ | ❌ | 临时编号 |
| 有效 | ✅ | ✅ | ✅ | 正式编号 |
| 停用 | — | — | — | 正式编号（沿用） |

状态机：

```
新增/复制入库（开启工作流的对象）
   │ 生成临时编号
   ▼
[待审批] ──用户修改──► 保持[待审批]
   │ 提交审批                 │ 工作流关闭：可直接转[有效]
   ▼                        │ 工作流更换：按新流程重新发起
[审批中] ──驳回──► [待审批] ◄── 撤回流程
   │ 审批通过
   ▼
赋正式编号（走对象名称规则）
   ▼
[有效] ⇄ [停用]
```

## 2.4 审批交互与可见性

| **B、功能点** |  |
| --- | --- |
| **功能点** | **描述** |
| 可见性 | 1. 待审批/审批中的数据：**默认创建人可见；对其他人隐藏；对管理授权的授权权限人可见**<br>2. 转正后按原数据可见范围规则 |
| 提交审批 | 待审批状态下用户点击"发起审批" → 进入审批中，数据锁定（不可修改、删除） |
| 修改重提 | 待审批状态下用户可修改内容、可删除数据；修改后重新发起审批 |
| 驳回 | 审批驳回 → 数据退回"待审批"状态，用户可修改后重新提交，直至通过或主动删除 |
| 撤回 | 审批中状态下可撤回流程 → 数据退回"待审批" |
| 审批通过 | 系统按对象名称规则赋正式编号，状态转为"有效"，此后可被引用 |
| 转正后编辑 | 编辑不再走审批，直接生效（与无工作流对象行为一致） |
| 批量粒度 | 批量复制/新增产生的多条临时数据**逐条独立**走工作流，各自审批转正，互不影响 |

## 2.5 工作流变更处理

| 场景 | 处理 |
| --- | --- |
| 关闭工作流 | 存量"待审批"数据：可重新发起审批走原流程，或直接变为"有效"状态 |
| 更换工作流 | 存量"待审批"数据：按新挂载的工作流重新发起审批 |
| 更换/关闭时处于"审批中" | 需当前流程审批完成，或撤回流程后再按上述规则处理 |
| 存量"有效"数据 | 对象开启工作流不影响已存在的有效数据，仅新增/复制走审批 |

## 2.6 各模块对临时/审批中数据的处理

| 模块 | 处理规则 |
| --- | --- |
| 对象列表 | 待审批/审批中数据按可见性规则显示，状态列显示对应状态标签 |
| 对象详情 | 可正常查看；操作按钮按权限矩阵控制（待审批可编辑/删除，审批中锁定） |
| 关联查找/汇总/公式 | 不纳入临时/审批中数据的计算 |
| 实体关系图 | 待审批/审批中实体仅创建人及授权人可见；无权限用户显示占位 |
| 关联结果/子对象/引用关系 | 临时/审批中实体不显示引用关系（未被允许引用） |
| 复制 | 仅"有效"状态实体可发起复制 |
| 导入导出 | 导出含临时数据（按可见性）；导入数据不走审批（直接入库） |
| ELN/样品引用 | 不可引用临时/审批中实体 |

# 三、功能清单

| 主模块 | 次级模块 | 功能名称 | 功能简述 | 优先级 |

| Registry | 科研数据注册 | 审批状态流转 | 待审批/审批中/有效/停用四态流转，临时编号与正式编号转换 | 高 |
| Registry | 科研数据注册 | 临时数据管控 | 禁止引用、可见性控制、锁定规则 | 高 |
